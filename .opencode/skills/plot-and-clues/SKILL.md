# 因果链悬念伏笔工程｜阶段 Skill

## 任务边界
- 承接 `chief-narrative-editor` 总控，聚焦当前阶段，不擅自跨过尚未验收的阶段。
- 读取本目录的完整 `prompt.txt`；其中的原始要求不得用简写代替。
- 必备输入：{{outline}}、{{story-bible}}。
- 目标产物：`outline.md`（作品专属目录），除非用户要求只在对话中查看。

## 执行流程
1. 检查故事类型，读取所属 `genre-*` Skill 与该作品的 `brief.md`、`story-bible.md` 或 `outline.md` 中可用的内容。
2. 根据 `prompt.txt` 开展本阶段工作，标记缺失输入以及待核查的事实。
3. 产出可交接文档，写清下一阶段必须继承的**已确认事实**和**尚未解决的问题**。
4. 自检是否满足本阶段验收要求；发生重大逻辑/事实问题时退回正确的上游阶段，不以文辞粉饰。

## 输出与责任
- 不泄露私人推理记录；交付对写作有用的方案、证据、章纲、正文或修改决定。
- 不在没有证据时推断非虚构人物的真实行为、动机或言论。
- 不改变已锁定的人物边界、规则和时间线，除非明确记录变更原因。
- 若涉及正式正文，在改动前留存审定版/初稿，避免丢失版本。
