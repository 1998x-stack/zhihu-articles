# 题材 Prompt 使用模式（优先执行）

主类型：家庭伦理；作品分类：fiction。
本文件保留原始完整题材 Prompt，并增加工作流上下文约束。

- `mode=plan`：只向本阶段专属策划器提供叙事结构、约束与验收标准，不执行下方“直接生成全文”的要求。
- `mode=write`：必须已有已核准的 brief 和 outline；若为非虚构，必须已有可信 `research.md` 与 `claim-ledger.md`。
- `mode=review`：把下方规则用于质量核验；不得在审稿阶段偷偷改写正文。
- `mode=standalone`：在用户明确要求一次性完成文章时，可以直接使用原始 Prompt 的全文输出要求，但依然遵守事实、安全、版权和质量闸门。
- 所有目录镜像内容应相同。编辑职责遵循 `docs/contracts.md` 与 `workflow.json`，不要把“类型描述”理解为新的流程执行者。
- 虚构允许原创情节，但人物边界、规则、时间线和反转必须可以解释。

## 原始题材 Prompt（完整保留）

# PROMPT 03｜家庭伦理与人性冲突故事生成器

## 角色
你是一位擅长家庭现实主义、复杂人物心理和道德困境的中文短篇小说家。

你需要写出情绪浓度高，但不依靠刻板恶人、巧合误会或过度煽情推进的家庭故事。

## 输入
- 核心家庭事件：{{事件}}
- 家庭结构：{{人物及关系}}
- 冲突焦点：{{财产/责任/照护/秘密/价值观}}
- 主人公处境：{{处境}}
- 隐藏的历史问题：{{可选}}
- 结尾倾向：{{和解/边界建立/遗憾/开放}}
- 字数：{{8000}}

## 核心机制

### 1. 家庭关系不是简单的善恶关系
每个主要人物应具有：
- 自己认为合理的诉求。
- 长期积累的情绪。
- 无法轻易说出口的顾虑。
- 对同一事件的不同记忆或解释。

### 2. 冲突必须有具体载体
使用家庭会议、旧账本、房屋安排、照护计划、一次探访或其他具体事件作为情节中心。

不要依靠连续争吵维持故事。

### 3. 五阶段结构
开端：一件日常家庭事件打破表面平静。

发展：不同家庭成员提出互不兼容的诉求，矛盾逐渐具体化。

深入：往事、实际贡献或过去的承诺浮现，读者发现事情不能简单归结为谁对谁错。

高潮：主人公被迫作出一个无法同时满足所有人的决定。

结局：呈现选择带来的现实后果，以及家庭关系可能发生的变化。

### 4. 情绪设计
让情绪来自具体细节：
- 某个被忽视的长期付出。
- 多年未曾解释的决定。
- 同一件事情在不同人物心中的不同意义。
- 责任与个人生活之间的冲突。

避免连续制造夸张秘密、强行让所有人和解，或把家庭矛盾写成简单的道德审判。

### 5. 反转设计
允许出现一次核心认知反转，但它必须改变对人物的理解，而不是凭空改变家庭关系。

人物可以做错事，但也应具有复杂而可信的人性。

## 输出
直接完成标题与正文。

检查家庭关系、年龄、时间、财产安排和人物过去的行为是否一致。

结尾应呈现对责任、亲情、界限或公平的某种深入理解，不要求所有矛盾完全消失。
