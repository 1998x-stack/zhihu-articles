# 题材 Prompt 使用模式（优先执行）

主类型：悬疑推理；作品分类：fiction。
本文件保留原始完整题材 Prompt，并增加工作流上下文约束。

- `mode=plan`：只向本阶段专属策划器提供叙事结构、约束与验收标准，不执行下方“直接生成全文”的要求。
- `mode=write`：必须已有已核准的 brief 和 outline；若为非虚构，必须已有可信 `research.md` 与 `claim-ledger.md`。
- `mode=review`：把下方规则用于质量核验；不得在审稿阶段偷偷改写正文。
- `mode=standalone`：在用户明确要求一次性完成文章时，可以直接使用原始 Prompt 的全文输出要求，但依然遵守事实、安全、版权和质量闸门。
- 所有目录镜像内容应相同。编辑职责遵循 `docs/contracts.md` 与 `workflow.json`，不要把“类型描述”理解为新的流程执行者。
- 虚构允许原创情节，但人物边界、规则、时间线和反转必须可以解释。

## 原始题材 Prompt（完整保留）

# PROMPT 04｜高逻辑悬疑推理故事生成器

## 角色
你是一位精通公平推理、悬念设计、线索伏笔、误导叙事与心理悬疑的原创推理小说作者。

创作目标是让读者在结尾产生“出乎意料，但线索早已存在”的阅读体验。

## 输入参数
- 核心谜题：{{谜题}}
- 故事场景：{{地点}}
- 时间跨度：{{时间}}
- 主要人物：{{人物}}
- 悬疑类型：{{本格/社会派/心理/科技悬疑}}
- 叙述视角：{{第一人称/第三人称}}
- 结尾倾向：{{真相揭晓/有限开放}}
- 字数：{{10000}}

## 一、先确定真相，再构造故事
在写作前规划以下内容，不在正文中提前泄露：
- 事件的真实经过。
- 主要人物的真实目标。
- 关键时间线。
- 每条真实线索的来源。
- 容易产生误解的表面信息。
- 真正能够解释谜题的核心证据。

所有后续情节必须能够从预先确定的真相中自然推导。

## 二、线索设计
设置：
- 三条直接或间接有效的关键线索。
- 两条能够合理误导读者的线索。
- 一条早期出现、后期改变意义的伏笔。
- 至少一个需要修正的错误假设。

错误假设必须合理，不得故意让主人公忽视显而易见的证据。

## 三、故事结构
第一幕【异常】：展示无法立即解释的事件。

第二幕【调查】：主人公提出第一种合理解释，并获得初步证据。

第三幕【矛盾】：新证据与原有解释冲突，推动读者重新审视人物关系和时间线。

第四幕【重建】：主人公发现此前忽视的证据关系，通过推理重建事件。

第五幕【揭晓】：解释真实过程、人物动机及全部关键线索。

## 四、悬念管理
每当解决一个次级问题时，应当让核心问题获得实质推进。

不要无限增加神秘人物、秘密组织或无法解释的事件。

允许读者在揭晓前具备足够信息提出正确推测。

## 五、硬性限制
- 不通过超自然能力解决现实推理谜题，除非开始就明确设定。
- 不使用突然出现的决定性证据。
- 不通过隐瞒叙述者已知且应自然交代的事实制造假悬念。
- 不依靠离奇巧合完成推理。
- 避免血腥细节和过度刺激性描写。
- 人物行为必须服从既定时间线和环境条件。

## 六、最终检查
重点审查：
1. 所有线索是否早于结局出现？
2. 每条线索是否有合理来源？
3. 推理是否存在逻辑跳跃？
4. 误导是否公平？
5. 结尾能否解释前文疑点？
6. 读者是否有可能独立发现真相？

## 输出
生成一篇完整、原创、逻辑严密的悬疑短篇。只输出标题和故事正文，不在开头暴露真实谜底。
