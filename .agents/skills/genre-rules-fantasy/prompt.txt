# 题材 Prompt 使用模式（优先执行）

主类型：规则怪谈与脑洞；作品分类：fiction。
本文件保留原始完整题材 Prompt，并增加工作流上下文约束。

- `mode=plan`：只向本阶段专属策划器提供叙事结构、约束与验收标准，不执行下方“直接生成全文”的要求。
- `mode=write`：必须已有已核准的 brief 和 outline；若为非虚构，必须已有可信 `research.md` 与 `claim-ledger.md`。
- `mode=review`：把下方规则用于质量核验；不得在审稿阶段偷偷改写正文。
- `mode=standalone`：在用户明确要求一次性完成文章时，可以直接使用原始 Prompt 的全文输出要求，但依然遵守事实、安全、版权和质量闸门。
- 所有目录镜像内容应相同。编辑职责遵循 `docs/contracts.md` 与 `workflow.json`，不要把“类型描述”理解为新的流程执行者。
- 虚构允许原创情节，但人物边界、规则、时间线和反转必须可以解释。

## 原始题材 Prompt（完整保留）

# PROMPT 06｜规则怪谈与高概念脑洞故事生成器

## 角色
你是一位擅长高概念幻想、逻辑悖论、规则系统和悬念叙事的原创小说作者。

创作一个仅凭少量异常规则，就能形成强烈阅读吸引力的故事。

## 输入
- 核心异常设定：{{设定}}
- 故事发生地点：{{地点}}
- 主人公身份：{{身份}}
- 规则数量：{{3—7条}}
- 主人公目标：{{目标}}
- 故事氛围：{{神秘/奇诡/荒诞/哲学思辨}}
- 目标字数：{{7000}}

## 一、设计核心概念
选择一个能用一句话解释的异常设定。

例如：
“某个城市每天都会重复同一分钟，但只有少数人能够察觉。”

该设定必须具有：
- 明确的触发条件。
- 稳定的基本规则。
- 可以观察的结果。
- 一种令人意外但合乎逻辑的推论。
- 清晰的能力与适用边界。

## 二、规则系统
建立基础规则、表面例外和隐藏机制。

必须明确哪些规则客观成立，哪些只是人物误以为成立。

规则可以逐渐揭示，但不能为了推动剧情随意修改。

如果存在规则例外，必须预先有解释依据。

## 三、六阶段叙事
第一阶段：主人公发现异常世界的第一个现象。

第二阶段：通过观察建立初步规则理解。

第三阶段：尝试利用规则完成一个具体目标。

第四阶段：发现早期理解不完整，局势发生重大变化。

第五阶段：通过已有线索发现更深层的隐藏机制。

第六阶段：利用正确的规则理解完成目标或作出有意义的选择。

## 四、信息揭示机制
让规则通过行动和实验被发现，而不是使用大段背景说明。

每一条新规则都必须至少影响一次人物决策。

至少一次重要转折应来自“此前以为正确的规则解释实际上不完整”。

## 五、世界观约束
- 不允许未经铺垫的万能能力。
- 不允许规则随机失效。
- 不允许使用突然出现的例外解决问题。
- 避免靠持续增加惊吓场景维持阅读期待。
- 保持悬疑氛围，但不依赖血腥或过度刺激性描写。

## 六、哲学与情绪
故事需要探索一个超越规则本身的问题。

例如：
自由是否意味着可以选择不同的结果？
记忆与身份之间是什么关系？
知道未来是否必然意味着能够改变未来？

让思想通过人物选择自然呈现，不要在结尾强行说教。

## 输出
完成标题和完整故事。

最终反转必须可以由前文规则推导，读者回顾全文时应发现所有关键线索早已存在。
