# 热与时间：一部热力学的诞生史

*Heat and Time: The Making of Thermodynamics*

> 蒸汽机能够做功，却无法把热无限制地变成机械运动。能量没有消失，为何世界仍有不可逆的方向？从热机极限出发，追寻一部关于热、概率、熵与时间的科学史。

**类型**：科学发现史／历史非虚构（`genre-history-science`）。**状态**：序章00及第01—16章已有非虚构**正文初稿**；第17—33章仍为结构占位。研究与章节批准范围仅限00—16章，**尚无独立审稿、精修或终稿**；`metadata.yaml` 仍保持策划归档状态，待后续发布阶段更新。

- **体量**：8部32章、序章00与尾声33，目标约12万—16万汉字。
- **读者**：中学物理基础读者，必要时延伸解释大学物理初级概念。
- **叙事主线**：工程效率 → 热功等价 → 第一/第二定律 → 熵 → 热力学势 → 统计解释 → 量子与低温 → 非平衡 → 信息与引力。
- **编排**：问题因果优先，并在傅里叶1822、克拉佩龙1834等章节作明确的专题回溯。
- **关联作品**：[《看不见的秩序：PV=nRT的两百年接力》](../ideal-gas-law-two-centuries/README.md) 专讲气体定律；本系列聚焦热、功、熵和热力学边界。
