# 奖励之后：一部强化学习思想发展史

*After Reward: A History of Reinforcement Learning*

> 2025年，2024年度图灵奖授予萨顿与巴尔托。早年研究如何让机器通过反馈学习的人，为什么最终成了今天人工智能的基础人物？这条路并不是从一台会下棋的电脑直接通往聊天模型，而是几条曾经分离的思想之河不断相遇。奖项公布时间见 [NSF 官方公告](https://www.nsf.gov/news/ai-pioneers-andrew-barto-richard-sutton-win-2025-turing)。

**分类**：科学思想史／人工智能发展史／非虚构知识连载。**规模**：八部32章＋序章、尾声，约15万字（编辑目标）。**状态**：`planning`；全部34个章节文件是占位，未完成正文、逐章原始文献核验、独立审稿或终稿批准。

## 一、贯穿全书的问题

**一个智能体若得不到标准答案，只能行动、观察后果并承担代价，如何逐渐学会更好的长期决策？**

这不是算法百科，也不是伟人传。每一次突破都必须回答四个问题：**旧办法解决了什么？被什么事实或条件卡住？新的方法付出什么代价才跨过去？它又把什么问题留给后来者？**

选择“奖励之后”作为书名，是因为奖励只提供评估信号；能否把它转成可靠的长期行为，贯穿全书。末章再追问：当奖励本身由人类偏好或答案验证器给出，优化目标与真正价值是否一致？

## 二、主线不是单一时间轴：三条源流，六条支线

1. **试错／心理学源流**：行为后果与行为改变；从动物学习的实验问题，到计算机器的反馈学习。不是简单一对一移植。
2. **控制／运筹学源流**：最优控制、动态规划、MDP、价值函数；最初可以无需从经验中学习。
3. **时序差分源流**：奖励到来之前，用预测变化修正预测；与前两条在20世纪后期逐步汇合。

汇合后形成价值学习、策略梯度、函数逼近、规划、自我对弈、偏好／奖励学习等并行支线。可从 [概念依赖图](concept-map.md) 查看交汇关系，避免把 Q-learning→DQN→AlphaGo→RLHF 写成唯一正统祖谱。上述三源流划分参考 [Sutton & Barto (2018)](https://mitpress.mit.edu/9780262039246/reinforcement-learning/) 的早期历史综述。

## 五、需要写透的核心转折

| 转折 | 旧问题 | 新解释／工具 | 不得忽略的代价或边界 |
| --- | --- | --- | --- |
| 试错 → 长期决策 | 只奖励当下不足以指导未来 | Bellman与状态价值 | 需要状态、转移及目标假设 |
| 知道模型 → 依经验学习 | 真实环境转移未知 | TD、Q-learning、Dyna等路径 | 采样与探索问题出现 |
| 学动作价值 → 学策略 | 离散动作表难应对高维连续控制 | REINFORCE、Actor-Critic | 梯度方差、稳定性 |
| 表格 → 深度网络 | 状态无法枚举 | 近似价值函数、DQN | 致命三角、复现实验 |
| 深度网络 → 搜索与自我对弈 | 只靠直觉难以推演复杂棋局 | AlphaGo／Zero／AlphaZero | 规则已知、算力与自博弈环境依赖 |
| 模拟棋盘 → 未知环境 | 真实世界无法无限试错 | PPO、SAC、MuZero、offline RL | 样本成本、分布偏移、安全 |
| 手写奖励 → 偏好与验证 | 复杂目标无法用单一数字精确定义 | RLHF、DPO、GRPO等不同框架 | 偏好代理、奖励误设与泛化 |

## 七、知乎盐选式知识叙事协议

**注意力设计**：用“程序自己学会比作者更强的跳棋”“强化学习的三个合理组件反而让训练崩溃”等可核问题开篇；绝不用虚构实验戏剧化故事。  
**阅读期待管理**：每章都写“当前可行→新限制→试错或方法发明→证据与反例→下一章问题”，每 800—1,200 字提供具体知识增量（为编辑目标，非硬性史实）。  
**价值兑现**：交付一个可以读懂/演算的最小例子、一条可追溯来源主张、一种常见误解的纠偏；结尾不是口号而是新问题的严格边界。

每个公式给三层讲解：**直观处境 → 数学定义与变量 → 何时会失败**。章节来源用 `research.md` 的 ID 建立 `draft/NN.claims.json`；仅进入正式正文阶段时生成，绝不预填假的审核数据。
