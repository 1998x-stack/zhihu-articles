# 事实核证与贡献归属清单

## 每章入稿前

- [ ] 阅读 `research.md` 的该章相关 R 编号原始论文或一手史料，记录具体页／节与版本。
- [ ] 核对“论文首次公开时间”“期刊出版时间”“赛事发生日期”是否被混用。
- [ ] 将一手文本、学界解释、争议判断、现代符号重构分别标注。
- [ ] 对“首次”“证明”“战胜人类”“从零”“不需要模型”等强限定术语作针对性证据检查。
- [ ] 至少查找一次竞争路径、独立发现、此前工作的贡献；避免简单英雄史。
- [ ] 对所有数学表达验证假设与反例，必要时做数值小实验。
- [ ] 多臂老虎机 ≠ 完整强化学习；动态规划 ≠ 已在未知环境学习；DPO ≠ 传统在线RL。
- [ ] RLHF的偏好标签、奖励模型与策略优化流程分别讲清；GRPO与可验证奖励从何而来也需拆开。
- [ ] 预印本和期刊论文相隔年份时分别列明。
- [ ] 无可靠证据的动人轶事必须删掉或显著标明来源不足，不做断言。

## 状态规则

本目录的研究索引和章节占位不能直接满足 `evidence_verified`。每完成一批证据核证，须记录章号、逐条来源和明确核证范围；大纲审核也应以实际证据为前提。按 AGENTS.md 使用仓库的 `workflow_gate.py` 以及 `workflow_state.py`，不凭编辑计划自动标记 PASS。
