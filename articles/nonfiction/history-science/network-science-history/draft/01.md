# 第一部·第一章｜七座桥的困局：欧拉删掉了距离

> **非虚构章节初稿｜证据追踪已建立，待全书工作流的正式审稿与封版。** 本章历史叙述以欧拉原文及欧拉档案为依据；图论符号、现代定理与示范路线属于明确标出的后世数学表述。

七座桥摆在一座城市里。

你可以从任意地点出发，可以选择任意方向，可以在一片陆地上来回走动。只有一条规则：**每座桥必须走过一次，而且只能走一次。**

这听起来不像一道难题，更像一种需要耐心的消遣。走错了？换一条路。走进死胡同？下次换一个起点。

然而，真正让这道题成为数学史上重要事件的，并不是有人迟迟找不到路线。

而是这样一个问题：

**你怎么知道，自己找不到路线，是因为选错了路，还是因为这条路线根本不存在？**

如果还有一万种走法没有试过，凭什么断言所有尝试都会失败？

十八世纪的柯尼斯堡，就把这样一道题留给了莱昂哈德·欧拉。

他最终没有交出一条成功的路线。

他证明了：任何人都不可能交出那条路线。

而这场证明里，最关键的一步，是把一座城市的大部分细节从问题里删掉。

## 一、一座城市，七座桥，和无数条看似可能的路线

当时的柯尼斯堡（Königsberg，今俄罗斯加里宁格勒）位于普鲁士。普雷格尔河流经城中，河道和岛屿将可步行的陆地分成了四个区域，七座桥连接着它们。

这里不必想象一场盛大的城市比赛，也不必虚构市民每逢周日相约走桥的对话。可以直接核实的事实是：欧拉在论文第2节交代了自己听说的过桥问题，并把四片陆地记为 A、B、C、D，把七座桥分别记为 a 至 g。他记述了关于能否完成这一行走的不同判断，却没有为这些判断编造具体当事人的故事。[1][2]

设想你只关心跨桥的顺序，而不关心在陆地上散步的曲折程度。这七座桥的连接关系可以整理成下面的表：

| 连接的陆地 | 桥的数量 |
|---|---:|
| A 与 B | 2 |
| A 与 C | 2 |
| A 与 D | 1 |
| B 与 D | 1 |
| C 与 D | 1 |
| **合计** | **7** |

A 是河中重要岛屿所在的区域；在这里，B、C、D 只作为其余三片陆地的符号。它们在纸上摆在什么方位，并不影响本章要研究的性质。

这意味着：在 A 与 B 之间，虽然有两座不同的桥，但从“下一步能到哪里”的角度看，它们把同一对区域连接了两次。这种情况在现代图论里叫作**平行边**。

数一数每片陆地连接的桥：

| 陆地 | 相接桥数 |
|---|---:|
| A | 5 |
| B | 3 |
| C | 3 |
| D | 3 |

四个数字：**5、3、3、3**。

它们看起来只是地图上的统计信息。

但接下来，这四个数字会比整个城市的地图更有用。

## 二、为什么不能把所有路线试一遍？

最直接的办法，是枚举。

从 A 出发，先走第一座桥，再选下一座桥；如果最后有桥没走完，就换一种顺序。也可以从 B、C、D 出发，重复尝试。

这种方法并非逻辑上错误：如果真的能穷尽所有路线，它当然能够判断是否有解。

欧拉自己也讨论过这种方案。在原论文第3节，他指出：对七座桥枚举全部行走已经繁琐；遇到更多桥时，枚举的代价会变得更难接受。相比之下，他想寻找一种只回答“是否可能”、而不必检查每条路线的方法。[2]

这就是整件事最深的转折。

普通的寻找路线，是把注意力放在**下一步怎么走**。

欧拉所追求的，是先弄明白：**任何成功路线必须满足什么条件？**

前一种问法，把人困在无数次选择之中。

后一种问法，却可能只需要几个数字。

在此之前，人们当然已经知道道路、桥梁与位置之间存在关系；“只研究位置而不研究大小”的想法，也并非由欧拉凭空提出。他在论文一开始便提到莱布尼茨设想过的 *geometria situs*，通常译作“位置几何”。欧拉认为，桥梁问题与测量长度和计算面积的传统几何不同，适合成为这种研究方向的例子。[2][4]

但一个研究方向的名称，本身不能解题。

他还需要找到那个真正不变的性质。

## 三、欧拉的第一刀：把路程从地图上删掉

想象同一座城市发生了三件事情。

第一，一座桥被加长一倍，但桥的两端仍连接原来的陆地。

第二，河道改变形状，地图上的桥弯曲得像一条弧线。

第三，整个地图被画得很小，四片陆地缩成四个点，桥缩成连接点的线。

过桥问题的答案会因此改变吗？

不会。前提是桥与陆地之间的连接关系没有变，且我们不设置时间、体力或桥面通行方向之类的新限制。

这个**不改变答案的部分**，就是抽象应当保留的东西。

在现代数学语言中，我们把陆地看作顶点，把桥看作边。顶点的集合写成 V，边的集合写成 E；整张图写成 G=(V,E)。

重要的是，这里**不能把 A 与 B 之间的两座桥合并成一座**。我们要逐座走桥，因此每座桥都必须保留独立身份。现代术语中的这张图，更准确地说，是一张允许平行边的无向多重图。

需要强调一处常见的历史误写：欧拉原文并没有把今天教材里那种“四个圆点、七条连线”的图，当作已经成熟的现代图论形式来呈现。论文使用陆地与桥梁示意图，并通过字母序列组织推理。今天的点—边图，是对其思想的便利重述。[2][3]

这个区别并不是吹毛求疵。

它能让我们看到科学概念真正形成的过程：**先发现什么信息可以舍去，再逐渐发展出专门表达剩余信息的语言。**

你仍然拥有七座桥。

但河宽、桥长、弯曲程度、建筑物位置和行走速度，已经不再参加计算。

留下来的，只有谁连接了谁，以及连接了几次。

可问题依旧存在：这些信息怎样证明“不可能”？

## 四、八个位置，为什么需要九个字母？

这是原论文中最有意思的一段推理。

欧拉没有先写出我们今天熟悉的“奇数度顶点定理”。他从一个更加直观的记录方法开始。

假设你从 A 出发，走一座桥到 B，再走到 D，最后到 C。

那么这段旅程就可以写成：

**A → B → D → C**

三个箭头，代表三次过桥。

四个字母，代表起点和每次过桥后到达的区域。

因此，每走一座桥，字母序列就增加一个位置。走七座桥，一定得到：

**七次过桥，对应八个位置符号。**

无论你绕得多么复杂，无论从哪片陆地出发，序列都只能有八个位置。

现在看 A。

共有五座桥通向 A。倘若每座都要走一次，其中一些过桥必须形成“进入 A—离开 A”的配对。

例如，一个完整的中间停留是：

B → **A** → C

进入 A 用去一座桥，离开 A 又用去一座桥。

两座桥，配成一对。

五座桥无法全部两两配对，必然还剩下一座，只能担当整个旅程的起点或终点所使用的那条边。

所以，如果五座与 A 相接的桥都被走过，记录旅程的序列中，字母 A 必须出现三次。

同理，与 B、C、D 各自相接的都是三座桥。每个相应字母都必须出现两次。

于是，一张简单的计数表出现了：

| 必须出现的字母 | 次数 |
|---|---:|
| A | 3 |
| B | 2 |
| C | 2 |
| D | 2 |
| **总计** | **9** |

等等。

一条完整旅程明明只有八个位置。

可是为了走完全部七座桥，四种字母加起来至少要占据九个位置。

**八个位置，装不下九个字母。**

矛盾出现了。

欧拉就这样在原论文第4—9节中，把寻找路线的问题变成了一道计数的不可能性证明。无需列出所有路线，只需说明任何合格路线必定违反一个基本计数约束。[2]

这里有一点很值得记住。

“没有发现”只是在描述我们已经尝试过的情况。

“不可能存在”，则是在陈述一条能够覆盖**所有可能尝试**的数学结论。

二者之间，差了一整套证明的方法。

## 五、真正的秘密：进入一次，通常就得离开一次

接下来，我们换成现代图论的表达，再看一遍这个证明。

把某个顶点连接的边数，叫作它的**度**，记作 deg(v)。

一个中途经过的顶点，如果既不是整个旅程的起点，也不是终点，那么每进入一次，就需要沿另一条尚未使用的边离开一次。

因此，它所用到的边必然成双成对：

进入一条，离开一条。

所以中间顶点的度必须是偶数。

只有旅程的起点和终点可以不同：起点允许比进入多一次离开，终点允许比离开多一次进入。它们才可能具有奇数度。

这就导出一个必要条件：

> **如果一张无向图可以不重复任何边地走完全部边，那么奇数度顶点最多只能有两个。**

如果起点与终点不同，恰好允许两个奇数度顶点。

如果走完所有边后回到起点，那么所有参与行走的顶点度数都必须为偶数。

柯尼斯堡的问题呢？

四片陆地的度数分别是 5、3、3、3。

**四个奇数度顶点。**

它需要的起点与终点名额，超过了一条连续旅程能够提供的数量。

这就是为什么路线不存在。

而且这个结论与起点选择无关：从 A 出发没有用，从 B、C、D 出发也没有用。

它甚至不在乎你是否愿意走很远的路。只要每座桥必须恰好经过一次，四个奇数度的障碍就无法绕开。

值得注意的是：一个图的奇数度顶点数一定是偶数。因为每条边都为两端各贡献一次度数，于是全部顶点的度数之和为边数的两倍：

**∑ deg(v) = 2|E|**

右边是偶数。所以不可能恰好只有一个或三个奇数度顶点。

现代人称它为**握手引理**：把人当成顶点、两人之间的一次握手当成边，每次握手恰好让总握手次数增加二。

在欧拉的原文后半部分，也能找到每座桥被两端计数一次、总数为桥数两倍的对应论证。[2]

从一座城市到所有无向图，只隔着一个思想动作：不再问桥的名字，而改问连接的次数。

## 六、奇数度不超过两个，就一定走得完吗？

还差一个条件。

设想一张网络分成互不相通的两个部分。就算每个顶点的度数都是偶数，你也不可能靠一条连续的行走走遍两个部分的全部边。

原因很简单：它们之间没有连接。

所以，现代欧拉通路定理的完整版本，需要说明连通性。

对一张所有非零度顶点位于同一个连通分量的有限无向图：

- **全部度数都是偶数**，就存在一条走完每条边并回到起点的欧拉回路。
- **恰好两个顶点的度数为奇数**，就存在一条走完每条边、起点与终点不同的欧拉通路。
- **奇数度顶点超过两个**，就不可能存在这样的路线。

这是现代标准形式。不要把整套现代符号与证明细节，原封不动地说成欧拉1735年已经使用的语言。

为什么偶数度加上连通性就足够呢？

可以先从一个所有度数均为偶数的连通图出发。

任选一条没有使用过的边，沿着它前进。每到一个不是起点的顶点，假如你仍要继续，那么之前已经用掉的进入和离开边是成对的；在尚未走完时，不会只剩下一次无法匹配的进入而被迫停在其他顶点。

于是可以形成一个回到出发点的闭合行走。

如果它已经使用了所有边，任务完成。

如果还有没走过的边，由于有边的部分连通，已有闭合路线上的某个顶点一定能接触到未使用的边。再从那里走出一条闭合路线，将新的路线接到旧路线里。

重复这个过程，直到所有边都走完。

而恰好有两个奇数度顶点时，可以在它们之间暂时添加一条“数学上的虚拟边”，使所有度数变偶数，构造闭合路线后再把虚拟边删掉。

一条从其中一个奇数度顶点走向另一个的欧拉通路就得到了。

这种“拼接回路”的说明是现代构造性证明，不是要假称欧拉原文就按此流程叙述。[3]

到这里，最初的“不可能”已经升级成一种更实用的能力：

**给出任何一张符合条件的图，只要检查连通性和奇数度顶点数量，就能先判定欧拉行走是否存在。**

## 七、如果柯尼斯堡再多一座桥，会发生什么？

现在让我们对这座城市做一次纯数学的假设。

原来，B 与 C 之间没有直接的桥。

假设增建一座连接 B 与 C 的桥。先不管现实工程能否实施，仅看连接关系怎样变化。

原来的度数是：

A=5，B=3，C=3，D=3。

新增 B—C 一条边后，变成：

A=5，B=4，C=4，D=3。

奇数度顶点只剩两个：A 与 D。

整张图仍然连通，因此现在**存在**一条从 A 出发、在 D 结束、每座桥恰好走一次的路线。

不妨实际检验下面这串位置符号：

**A → B → A → C → A → D → B → C → D**

它跨越了八条边。

其中两次 A—B 分别使用原来的两座桥，两次 A—C 同理；A—D、D—B、C—D 使用原有桥，B—C 使用新增的桥。

没有一座桥重复使用。

也没有一座桥被遗漏。

我们没有修改地图的长度，没有求出最短路，甚至没有关心行走总时间。

仅仅加了一条特定的边，就让一个原本不可能完成的任务变得可能。

这里还藏着更深的一层：**并不是随意新增一条桥都有效。** 如果新增桥连接的是两个原本奇数度的区域，就可能把它们同时变成偶数度；而如果添加在其他连接上，奇数度顶点的分布可能仍不足以满足欧拉通路条件。

结构改变，结果改变。

但改变不是神秘的，而是可以计算、可以验证的。

这正是后来网络科学反复遇到的主题之一。

## 八、这真的算几何吗？欧拉面对的是另一个问题

我们习惯把数学与长度、角度、面积、体积放在一起。

但七桥问题里，桥长一点还是短一点，不影响是否可以完成那次行走。只要连接关系不变，结论就不会变化。

这使它很适合成为“位置几何”的样本。

在论文开头，欧拉提到莱布尼茨的 *geometria situs*。按照他的理解，要处理的并非传统几何中的量值，而是位置及其关系。这一历史语境尤其重要：欧拉所写的不是一本已经成熟的现代《图论教程》，而是试图说明一种不同于测量几何的研究方法为什么有意义。[2][4]

我们今天常常称它为图论的开端，甚至把它视为拓扑学的早期先声。这样的说法有其合理根据，但仍需谨慎。

第一，**图论、拓扑学与现代网络科学不是三个可以完全互换的名称**。它们后来各自发展了大量不同问题和方法。

第二，**欧拉并非凭一篇论文完成了全部图论**。后来有关树、回路、电路、随机图、社会网络的成果，来自不同时代与不同传统中的众多研究者。

第三，七桥模型刻意忽略了许多现实条件。如果一座桥只能单向通行，如果一条路在某些时间关闭，如果走完所有桥还要求最短时间，那么需要的模型就会变化。抽象能够带来力量，也必然伴随取舍。

因此，欧拉的突破不是告诉我们“世界上所有系统只要画几个点就都能解释”。

它教会我们一种更可靠的研究习惯：

**先弄清问题真正依赖什么；舍去与答案无关的细节；再寻找那些无论怎样尝试都不会改变的约束。**

## 九、七桥问题之后：下一场革命为什么会发生？

回到全书序章，我们曾经从1998年的小世界模型和1999年的枢纽模型出发。

那些研究讨论的网络，比七座桥复杂得多。

它们有数以万计、百万计甚至更多的节点，关系可能不断出现和消失，局部结构还可能影响信息传播、搜索效率和群体行为。

但欧拉提供的一种提问方式仍然有用：

**不要只看单个对象怎样行动，要看它所处的连接结构允许什么、禁止什么。**

在七桥问题里，局部的“相接桥数为奇数”，让全局的“恰好走遍所有桥”成为不可能。

这提示了网络研究中一个反复出现的方向：局部连接约束，可以限制系统能够出现的整体行为。

当然，这并不意味着我们已经得到了现代网络科学。七桥模型不涉及关系怎样形成，不讨论随机网络的典型性质，也不能解释流行病传播或社群分化。

它做成了更基础的一件事：展示如何把一个现实问题转化为清楚、可证明的连接问题。

接下来，数学家还需要回答：

如果桥梁不再只是“能不能走”，而变成可以传递电流的导线，或者数量极多、需要系统计数的树形结构，单靠奇偶性还够用吗？

答案显然不够。

**从判断一条路线存在与否，到计算整个连接系统的性质，下一批数学家必须发明新的工具。**

这就是下一章《从电路到树：连接开始拥有方程》的起点。
