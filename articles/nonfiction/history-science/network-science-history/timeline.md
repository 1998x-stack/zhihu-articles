# 网络科学发展时间轴

注意：主题卷次不完全等于严格年代顺序。几条研究传统长期并行；第五部回溯1927年是为解释理论前史。

| 年代 | 关键阶段 | 研究问题 |
|---|---|---|
| 1736 | 欧拉七桥 | 路是否存在 |
| 1840s—1880s | 电路与树 | 怎样计数和计算连接 |
| 1908—1927 | 罗斯、赫德森、克马克—麦肯德里克 | 疫情增长、移出和门槛的数学前史（第五部回溯） |
| 1930s | 社会测量学 | 人际关系怎样可视化 |
| 1959—1960 | 随机图 | 何时出现巨型分量 |
| 1967—1979 | 小世界、弱关系、中心性及1978行为阈值 | 结构与个人门槛怎样影响信息和行动 |
| 1990s | 互联网与WWW研究 | 真实网络与理论差多少 |
| 1998 | Watts–Strogatz | 高聚类和短路径如何共存 |
| 1999 | Barabási–Albert | 枢纽为什么形成 |
| 2000—2002 | 鲁棒性、社群、模体、2001 SIS网络传播、2002级联 | 结构与动力规则怎样共同决定结果 |
| 2004—2009 | 模块度、Louvain、幂律检验 | 模型和算法如何评价 |
| 2010s | 时间、多层、图嵌入、GNN | 静态结构之外如何描述与学习 |
| 2020s | 高阶相互作用、网络因果和图AI | 预测与解释的边界 |
