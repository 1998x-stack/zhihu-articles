# 网络科学发展时间轴

注意：主题卷次不完全等于严格年代顺序。几条研究传统长期并行；第五部回溯1927年是为解释理论前史。

| 年代 | 关键阶段 | 研究问题 |
|---|---|---|
| 1735—1741 | 欧拉七桥E53：1735研究/报告、1736期卷、1741实刊 | 仅保留相接关系能否严格判定路线存在性 |
| 1840s—1880s | 电路与树 | 怎样计数和计算连接 |
| 1908—1927 | 罗斯、赫德森、克马克—麦肯德里克 | 疫情增长、移出和门槛的数学前史（第五部回溯） |
| 1930s | 社会测量学 | 人际关系怎样可视化 |
| 1959—1960 | 随机图 | 何时出现巨型分量 |
| 1967、1975 | Winfree群体耦合振荡与Kuramoto相位模型 | 节奏不同的节点怎样自发相互协调（第五部回溯） |
| 1967—1979 | 小世界、弱关系、中心性及1978行为阈值 | 结构与个人门槛怎样影响信息和行动 |
| 1990s | 互联网与WWW研究 | 真实网络与理论差多少 |
| 1997—1999 | Kleinberg HITS、PageRank与Google原型 | 链接怎样成为枢纽/权威评分和递归网页排序 |
| 1998 | Watts–Strogatz | 高聚类和短路径如何共存 |
| 1999 | Barabási–Albert | 枢纽为什么形成 |
| 2000—2002 | 鲁棒性、社群、模体、2001 SIS传播、2002级联及时间图 | 动力规则和事件顺序怎样改变结构结论 |
| 2004—2009 | 模块度、Louvain、幂律检验、2005网络同步谱分析 | 模型和算法如何评价，网络结构如何影响相位协调 |
| 2011—2012 | 时间中心性实证及时间网络综述（早于此已有2002理论） | 把传播的前后顺序与等待限制带回网络分析 |
| 2001、2008—2011 | 同质性交友、网络干扰因果框架、观察性混杂研究 | 相关性、先后与真实同伴影响为什么不能混同 |
| 2010、2014 | 依赖网络故障模型与多层网络系统综述 | 边的类型及层间耦合怎样改变功能与脆弱性 |
| 2016、2019、2020 | 高阶模体、单纯复形传播与多体网络综述 | 同时群体事件为何不总能拆为两两接触 |
| 2003—2007 | 合作网络链接预测与结构接近性 | 从观察已有边到评价下一条可能出现的边 |
| 2014—2016 | DeepWalk与node2vec | 用随机游走和上下文学习节点向量 |
| 2008—2009、2016—2019 | 早期GNN、GCN、GraphSAGE、MPNN和表达能力理论 | 从邻居特征聚合到归纳式表示与结构辨别界限 |
| 2018—2021 | GNN过平滑与长程信息过压缩研究 | 更深的邻居聚合何时损失信息 |
| 2009 | Pearl因果推断概览综述（延续此前理论） | 为什么观察性预测不等于识别干预效果 |
| 2018、2020 | GNN评价陷阱研究与Open Graph Benchmark统一评测 | 不同数据拆分与评测目标怎样改变模型比较 |
| 2010s | 图学习与机器预测广泛研究 | 在时间与多种边语义之外如何描述、预测与解释 |
| 2020s | 高阶相互作用、网络因果和图AI | 预测与解释的边界 |
