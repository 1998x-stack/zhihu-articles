# 盐选式科学史写作规则

文章的吸引力来自真实的认知难题，而不是虚构对话或离奇轶事。每章采用：反常的研究问题 → 旧方法为何失效 → 历史参与者与新证据 → 定理的最小示例 → 验证及局限 → 真实而自然的下章悬念。

讲解分三层：生活直觉、准确机制、模型边界。公式交代变量和适用条件；不同年代概念不能倒灌。特别注意幂律、传播阈值、六度、社群、中心性、因果等容易被过度简化的概念。

优先使用具体历史文献与可复核数据，明确区分事实、争议、作者解释和现代类比。不得编造科学家对白、私下心理、实验记录。目标每章3500—5500汉字；实际完成草稿后，按仓库非虚构工作流完成事实核查、连续性审计和独立结构审稿。
