# 失去确定性：数学史上的三次危机与七次思想革命

> 一条对角线、一个消失的无穷小、一封1902年的来信：数学怎样一次次重写自己可相信的规则？

**作品性质**：历史与科学发现／数学思想史非虚构长篇。当前状态 **drafting（第01—08章已有长篇初稿，其余章节为占位）**。

- 目标读者：有高中数学基础、喜欢知识叙事的普通读者；延伸覆盖高中生、大学生和理工背景人群。
- 体量：约13万汉字，6部25章，另有序章与尾声；每章拟4000—6000字，允许调整。
- 论旨：经典“三次危机”是一种后见式的组织框架，不是古今数学家一致认可的固定事件名单。“七次思想革命”是本书**编辑性分段**，不是学界公认的历史计数。
- 主类型：`genre-history-science`；使用总控主编、事实核查、结构策划和独立审稿规范。
