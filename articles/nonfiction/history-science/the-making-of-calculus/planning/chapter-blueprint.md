# 章级写作蓝图｜知乎盐选式知识叙事，但事实先于戏剧

**适用**：本专题37篇；**定位**：`nonfiction-writer` 写作前的编辑审稿规格，不能越过 `fact-research`、`nonfiction-architect` 的准入流程。

## 一、读者契约：每篇不是课本一节，而是一段真正有结果的调查

一章必须包含三个层次：

1. **注意力设计（开头）**：一个真实、可验证的矛盾。如「距离最短为何不是时间最短」，明确告诉读者要解的到底是什么，而不是玩神秘主义。
2. **期待管理（过程）**：读者看到「旧方法能做到哪里 → 突破需要什么前提 → 实际方法怎样工作 → 哪些人贡献不同」。每约800—1200字应出现概念、证据或结果的实质推进，不能仅重复悬念。
3. **价值兑现（结尾）**：读者能亲手验证一个小算例，能准确复述一个史实边界，能理解这个转折为何让下一章不可回避。

**基本禁令**：不写虚构的牛顿夜谈、莱布尼茨表情、伽利略当晚心声；不把后世数学记号暗中塞回古籍；没有可信资料不能把想象写成「据记载」。

## 二、八拍式章节结构（3500—5500字可灵活调整）

| 节拍 | 主要任务 | 自检问题 |
| --- | --- | --- |
| 1. 冷开场（约5—10%） | 以一段可核证的题目/文献/数学反常引入 | 问题能否用一句话复述？ |
| 2. 时代工具箱（约10%） | 交代当时已知道什么、可用哪些记号和方法 | 有无把后人概念穿越回过去？ |
| 3. 旧方法失败的位置（约10—15%） | 明确失败的条件而非把前人写成无能 | 有具体例子吗？ |
| 4. 人物与关键转折（约15%） | 以实证文献讲谁做了什么，以及不同版本 | 年代、归属、发表是否区分？ |
| 5. 一次可以复算的数学演示（约20%） | 从生活直觉进入最小必要公式、展示假设 | 每一步是否数学正确、符号定义清楚？ |
| 6. 反例／代价／竞争视角（约10—15%） | 交代此方法不适用的边界 | 是否夸大为万能方法？ |
| 7. 认知兑现（约10%） | 重新回答开头，必要时展示现代回译 | 读者能说清为什么是重大转折吗？ |
| 8. 因果钩子（约5%） | 提出下章必须接手的未解问题 | 删除这章会不会断掉历史链？ |

比例只是**节奏参考**；文献和数学复杂时可以调整，但不准因追求戏剧性删去适用条件。

## 三、三层数学解释，不把史书变成习题集

- **直觉层**：用一个可画图、可量纲检查的具体模型，不先扔十个公式。
- **机制层**：展示真实的推导或证明核心步骤；例如先展示割线斜率，再解释极限而不是直接宣布导数。
- **边界层**：说明收敛、连续、可微、可积等条件；历史人物原工具与现代解释严格分开。

推荐常驻的六类算例：割圆误差、抛物线弓形的4/3面积、位置—速度的差商、面积函数与反导数、黎曼上下和与勒贝格思维、计算图链式法则。每章只选最能实现本章价值的一个主例子，不机械套用全部。

## 四、历史写作的信息标签

**事实／解释／争议／现代回译**四类须分层：一个名人逸事若没有一手记录，不可伪装成现场；手稿年代、发表年份、后人归属不得混用。跨文化研究只对**同类问题如何不同地被解决**进行比较；有明确传播主张时另查手稿、译介和研究史。

章级来源记载至少覆盖：核心事件发生时的原材料（或可靠译本）、学术史学解释、数学演示正确性。对未获得原文的情形写「待核」，而不是自造页码。

## 五、正文准入与批次审核

**开写前**：核查该章 `research.md` 中的来源范围 → 对照 `claim-ledger.md` 与已核准 `outline.md` 的章节目标 → 运行仓库相应阶段的门禁；全书 `workflow-state.json` 尚未批准时，不得假称通过。

**写作后**：由 `nonfiction-writer` 负责 `draft/NN.md` 与 `draft/NN.claims.json`，再交 `continuity-audit` / `developmental-editor` 生成彼此独立的审核记录。只完成数学复算或来源查找，不等于独立审稿 PASS。

**三章一批**：建议按 `batches/README.md` 推进：第1章设置问题，第2章推广或争论，第3章揭露下一阶段局限；批次内部形成清晰知识递进。下一批17—19要特别回收序章「最速降线」悬念，不能把1696同年发生的挑战和教材当作同一事件。

## 六、内容质量阻断清单

任意一项成立，禁止升格为正式正文或出版稿：

- 关键年代、贡献归属、传播路径无可核验来源；
- 数学示例有公式、符号、条件或量纲错误；
- 把古人的猜想与后世严格证明混同；
- 把牛顿和莱布尼茨的争论描写成无来源心理剧；
- 只有惊人标题，没有真正讲清楚数学机制；
- 一章一段名人传，删掉后不影响全书因果链；
- `draft/NN.claims.json` 与正文断言不对应，或审稿修订后没有重做两道核验。

## 七、风格范例：有张力，但不是捏造

**建议的开场模式**：「1696年，一道公开征解的曲线问题要求人们找出下滑耗时最少的路线。直线最短，但最短距离为何不保证最短时间？」——接着说明理想模型与资料来源。

**应避免的模式**：「牛顿看完信后冷笑一声，随手写出答案，气得所有对手彻夜难眠。」——这是未经证实的私人动作和心理描写。

**建议的结尾模式**：「这一次，我们发现最短路程和最短时间并非同一优化目标；但一套可以跨问题教给别人的计算规则，为什么仍需要面对无穷小的逻辑质疑？」——自然转入后续章节。

**评价底线**：读者读完应当既获得故事推进，也能更准确地思考数学；真实性是进入评价的前提，而不是与戏剧性等权的可交换得分项。
