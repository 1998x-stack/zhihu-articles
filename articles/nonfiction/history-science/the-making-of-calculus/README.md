# 从切线到无穷：微积分的诞生与重建

*The Making of Calculus: From Tangents to Infinity*

> 一条曲线的切线和一片曲线下的面积，为什么竟是同一类问题？

**状态：outlined｜37篇有内容的策划占位文件，尚未撰写正文或通过史料审稿。**

主类型：历史与科学发现非虚构。目标读者：具有高中数学基础的普通读者。目标总篇幅：约13—20万字（每章建议3500—5500字）。

学习路线：**曲线求积 → 瞬时变化 → 两类问题互逆 → 微积分算法 → 基础质疑 → 极限和实数 → 广义积分和导数 → 现代计算**。

本系列与既有 [《失去确定性：数学史上的三次危机与七次思想革命》](../the-loss-of-certainty-math-crises/README.md) 互补：后者研究整个数学的基础危机，本系列具体追踪微积分如何解决问题、建立定理和修正定义。
