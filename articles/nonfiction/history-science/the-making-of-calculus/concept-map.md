# 概念因果依赖图

局部难题：切线 / 瞬时速度 → 导数；整体难题：曲边面积 / 体积 → 积分。

两线汇合：微积分基本定理（在相应条件下通过反导数求定积分）。

新矛盾：无穷小含混、无穷级数交换运算不可靠 → 极限、连续、一致收敛、实数完备性。

新反例：连续但不可微、函数过于不规则 → 黎曼/达布可积性 → 测度与勒贝格积分 → 函数空间和分布 → 现代可计算导数。

## 六个贯穿全书的可手算体验

1. 内接正多边形逼近圆面积。
2. 用平均速度估计瞬时速度的变化。
3. 对 y=x² 比较割线斜率，借助现代极限得到 2x。
4. 对 v(t)=2t 求区间位移，再对累计量求导以体验基本定理。
5. 比较阶跃函数与处处不连续函数的黎曼可积性（写作时细化条件）。
6. 对一个两层计算图应用链式法则，区分自动微分和数值差分。
