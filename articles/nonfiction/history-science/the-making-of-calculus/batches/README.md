## 批次工作契约

1. **研究**：`fact-research` 核查本批核心文献、年代、争议与计算，更新其拥有的 `research.md`；构建有具体页码的主张证据映射。
2. **结构**：在有效上游事实范围内，由 `nonfiction-architect` 更新其拥有的 `outline.md` 和 `claim-ledger.md`，必要时重新获取批准。
3. **写作**：由 `nonfiction-writer` 将现有 `draft/NN.md` 占位扩写为正文，并生成／更新对应 `draft/NN.claims.json`；不得移除既有章节的已核实内容。
4. **审稿**：进行数学独立复算、事实与概念连续性审计，另交独立结构审稿；若不通过则按修订版本重新审查。
5. **记录**：仅在真实完成闸门要求后更新 `series.json`、`workflow-state.json` 与 README 的状态；不得把历史文献目录视作 `evidence_verified=true`。

## 共通质量核查

每批三章应形成「实际难题 → 方法转换／传播 → 新问题」小弧线；每章交付可复算的主例、证据边界与下一章必须回答的问题。参照 [37章矩阵](../planning/chapter-matrix.md) 和 [写作蓝图](../planning/chapter-blueprint.md)。
