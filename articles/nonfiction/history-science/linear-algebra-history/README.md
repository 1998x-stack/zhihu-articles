# 从方程到空间：一部线性代数思想发展史

*From Equations to Spaces: A History of Linear Algebra*

> 一张用于解方程的算筹表，为什么最终会变成描述高维空间、量子状态和现代计算的通用语言？

**归类**：数学思想史／科学历史非虚构。**进度**：已建立 8 部 32 章、序章与尾声，第01—14章为已有来源对照的正文初稿，其余20个章节文件仍为策划占位，不是正式正文。预计 16—19 万字。

## 核心主线

研究并行演进的四条道路：**方程求解及最小二乘**；**行列式与矩阵代数**；**向量、空间和线性映射的抽象**；**谱理论与数值计算**。它们并非严格按教材顺序出现，最后在统计、量子力学、计算机科学中广泛交汇。

## 写作原则

1. 真实数学问题开篇；历史困境 → 竞争尝试 → 关键定理／方法 → 数学例子 → 局限与下章问题。使用具有阅读张力的非虚构表达，但不编造人物对白、日记、心理和不存在的竞争。
2. 每章研究须区分**史实、广泛接受的解释、存在争议的判断、现代教学重构**。文献索引不是全部主张已核实的证明。
3. 按仓库的非虚构阶段规范逐章推进；第01—14章已限定范围完成证据核对及章节架构审核；不代表其余各章通过核验，book.json 中第01—14章为 draft、其余20章为 outline；仍未通过全书终审，不应对外宣称已有正式成稿。
