# 全书路线与逐章大纲

## 一句话主问题

**线性代数为何从“求几个未知数”，发展成“研究任意维线性结构和可计算变换”？**

## 八次观念转换（编辑性分段，非学界固定称谓）

1. **方程的困境**：算筹、符号化、消元、超定方程和最小二乘。
2. **行列式的诞生**：从特殊求解公式到行列式的独立理论。
3. **空间被重新发明**：坐标、有向线段、四元数与高维扩张论。
4. **矩阵成为对象**：矩阵命名、乘法、特征多项式、秩与不变量。
5. **寻找不变的方向**：力学主轴、特征值、标准形与算子谱。
6. **向量空间的公理化**：公理、基与维数、模和无穷维空间。
7. **计算机重写算法**：稳定性、奇异值分解、QR与特征值算法。
8. **线性代数走向世界**：PCA、网页排序、量子理论与机器学习。

## 四条历史发展线索

- **求解线**：《九章算术》式消元 → 现代消元 → 观测误差与最小二乘 → 秩与可解性。
- **代数线**：早期行列式 → 克拉默 → 柯西和雅可比 → 西尔维斯特命名 → 凯莱矩阵代数。
- **几何线**：解析几何 → 有向线段与四元数 → 格拉斯曼扩张论 → 皮亚诺公理 → 基、维数和模。
- **谱／计算线**：力学主轴 → 特征值与标准形 → 希尔伯特空间 → SVD与QR → PCA、网页排序及现代计算。

## 第02章专题证据架构（2026-11-06；不改变原先全书规划）

- **起点与兑现**：从上一章 39／34／26 被现代符号写成 x、y、z 的“时代错位”进入；回答给未知数命名如何把具体解题推进为一般关系式。
- **并行证据路线**：丢番图《算术》的缩写式未知量（N02-S1）→ 9世纪花拉子米的语言方程与配方（N02-S2、N02-S3）；另线为中国《九章算术》筹算传统→李冶1248年天元术→朱世杰1303年四元术（N02-S4、N02-S5）。这些节点的排列是跨文明比较，不暗示彼此必然传授。
- **符号的拼接**：1557年雷科德的等号（N02-S6）；1591年韦达以元音/辅音区分未知量和给定量（N02-S7、N02-S8）；1637年笛卡尔推广 a、b、c 与 x、y、z 的常用记号（N02-S7、N02-S9）。
- **数学认知兑现**：给单独未知数命名不等于完成符号代数；给可变的已知参数也命名，才可以对整个方程族作一般求解。用二元系统 ax+by=p, cx+dy=q 消元得 ad-bc 作为唯一解条件（MATH-DERIVATION）。
- **限制与下章**：写出一般形式之后，还要系统研究每一步是否可执行、解是否存在/唯一；由此引出第03章“高斯之前已有消元”。

### 12 格拉斯曼1844：空间为什么不必三维

- **首问**：三个空间方向够用，为何要研究第四个乃至第n个独立方向？
- **铺垫**：承接11章哈密顿四元数的四实系数（不等于空间四维）与10章位移加法，回溯另一条不以复数乘法为唯一出发点的方向。
- **史实**：1844《扩张论》及原著前言中的位移加法、平行四边形有向乘积；形式化的独立方向和复合量；书写难度和接受障碍；1862新版、1867后续采用、1888 Peano公理化。
- **算法兑现**：R⁴四基向量；外积反对称，精确计算(u=e₁+2e₂)∧(v=3e₁+e₂+e₃)；不把外积简单说成高维叉积。
- **结尾压力**：空间的抽象量已有运算法则，线性关系中的系数表为何还没有被普遍视为对象？引13章。
- **对应证据**：C12-01—C12-06 / H12-S1—S4 / M12。

### 13 西尔维斯特：矩阵先有名字，还是先有理论

- **首问**：3行2列的系数表没有行列式，那它究竟算什么？
- **史实**：1850 Sylvester原始论文命名matrix，长方母体与选取p行p列的各阶子式；此时尚未完整现代矩阵代数；1853/1855 Cayley先行研究。
- **算法兑现**：3×2实例的三个2阶子式(-2,-4,-2)，以及全部2阶子式为0的对照例；后世秩概念仅作数学说明。
- **时间线**：不能把早期方程系数表、1850新词、1858矩阵代数视为同一天的同一发明。
- **结尾**：名字出现，什么运算能让表真正成为对象？引14章。
- **证据**：C13-01—C13-06 / H13-S1—S4 / M13。

### 14 凯莱1858：两次变换为什么可以相乘

- **首问**：两个系数表如何依次作用于同一个输入？
- **史实**：1857-12-10收到、1858-01-14宣读、1858期刊刊出，原著与皇家学会审稿文献；此前Sylvester命名与Cayley 1853/1855工作。
- **数学兑现**：A=[[1,2],[0,1]], B=[[1,0],[3,1]]，AB、BA相异，复合计算、单位元、逆、结合律解释；对线性映射合成遵守先右后左。
- **论证限制**：1858特征方程的早期讨论与第15章Cayley-Hamilton定理一般证明严格分开。
- **结尾**：一个矩阵真的能满足自己对应的多项式方程吗？引15章。
- **证据**：C14-01—C14-07 / H14-S1—S5 / M14。

### 20 希尔伯特与施密特：无限维也能谈谱吗
