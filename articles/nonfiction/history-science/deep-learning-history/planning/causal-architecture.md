## 二、把2012拆为五条必要而非单一充分的条件

1. 研究思想积累：卷积网络与反向传播**早已存在**。
2. 数据和公开竞赛：ImageNet与ILSVRC给出规模化训练与共同基准。
3. 计算与软件：GPU训练与工程实现降低实验成本。
4. 优化与正则化：ReLU、dropout、数据增强及调参策略协同。
5. 科研传播：可重复、可比较的公开结果带来社群路线调整。

**警告**：这是后人分析框架，不等于可以对各因素做已证实的精确因果贡献分解；不应声称某一要素“决定了全部”。

## 三、五次“故事反转”，必须由事实驱动

- 感知机能学习，却发现表达边界：**能学习并不意味着足够表达**。
- 多层网络能表达，却难以训练：**可表示并不等于可优化**。
- CNN能商业落地，却未统治所有场景：**局部成功不等于范式胜利**。
- 2012出现显著竞赛进展，却并非刚发明模型：**突破可能来自条件组合**。
- 大模型可生成复杂答案，却仍会失实：**能力指标不是可靠性证明**。

## 四、跨章回收设计

- **序章00→17→24→30**：2012为什么有效 → 规模规律边界 → 新模型评测与效率。
- **03→05→06→09**：从固定计算 → 权重学习 → 表达困难 → 隐藏层训练。
- **08→10→18**：视觉层级的结构思想 → CNN应用 → 残差可训练性。
- **11→20→22→23**：记忆瓶颈 → 注意力 → Transformer → 预训练。
- **13→19→24→28**：语言表示 → 序列训练 → 规模 → 对话产品。
- **25→26→27→31**：与搜索、科学约束、多模态结合 → 模型能力边界。
