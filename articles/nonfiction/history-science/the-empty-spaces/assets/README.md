## 第六章拟制图（未上传原图）

- **原创示意**：使用简化数值O16/S32、C12/Si28、Na23/K39、F19/Cl35标出圆柱上同朝向的点。必须标注“现代教学重绘，不等于1862版精确布局”。
- **史料对照**：[Linda Hall Library](https://www.lindahall.org/about/news/scientist-of-the-day/alexandre-emile-beguyer-de-chancourtois/)所示原图重绘；[法国国家图书馆1863年图本题录](https://catalogue.bnf.fr/ark:/12148/cb30077511j)，需进一步核对馆藏版面和印图版本。
- **历史实物**：[Science Museum Group模型](https://collection.sciencemuseumgroup.org.uk/objects/co13134/model-of-the-periodic-)制于1925年，其照片仅在CC BY-NC-SA 4.0等条款下使用；商业出版需单独取得许可。
- **科学比对**：标出同族相邻原子量差值未必等于16，避免只展示成功样本。

## 第七章候选图示与出版检查

- **1865年原版八音律表**：[Linda Hall Library 原印刷影像与研究说明](https://www.lindahall.org/about/news/scientist-of-the-day/john-r-newlands)。不得直接把网络照片用于付费出版；须核公共领域原印本与现代照片的权利。
- **原创教学重绘**：根据1865年原表数字表现Li2—Na9—K16及N6—P13—Mn20—As27的连续编号，明确“历史顺序编号，不是现代原子序数”。若展示完整表，准确标注Co&Ni等共享号码现象。
- **图像辨伪**：[Science History Institute晚期玻璃板](https://digital.sciencehistory.org/works/xg94hq04d)虽标“NEWLANDS 1865”，但含He、Ne等后发现元素，不是1865原始论文图，不能作为原物转载。
- **历史奖章**：1887年皇家学会[原始授奖通知馆藏目录](https://catalogues.royalsociety.org/calmview/Record.aspx?id=NLB%2F1%2F701&src=CalmView.Catalog)，优先用馆藏书目图而不未经授权复制信件影像。
