# 《空位》历史科学悬念叙事手册（V0.2）

> 服务于本书的长期章节写作；“知乎盐选风格”指高注意力、可持续阅读期待和有效的认知兑现，不模仿任何具体作者或受版权保护作品的独有表达。

## 章节叙事引擎

### 1. 注意力设计
- 开头100—200字优先呈现一个由真实资料支持的异常：矛盾数字、反直觉分类、难以解释的实验现象或人物遇到的实际难题。
- 不从百科式人物介绍开始，不用“震惊世界”“谁能想到”式空话。
- 开篇给读者一条可追查的事实，并提出一个能由本章回答的核心问题。

### 2. 阅读期待管理
- 按“异常 → 旧有解释 → 关键证据 → 反证或局限 → 新解释 → 后续问题”的逻辑推进。
- 新的一节必须推进时间、问题或读者理解，避免重复总结和无根据悬疑。
- 科学人物有不同认知边界；不能把事后的现代知识偷偷交给历史人物。
- 反转应重解先前信息，不得为制造悬念编造实验、信件、台词和心理活动。

### 3. 价值兑现
- **事实层**：发生了什么，谁参与，何时何地，资料出处？
- **机制层**：为什么旧解释不够，新观点如何得到实验支持？
- **思想层**：方法论改变了什么，还留下了哪些尚未解答的问题？
- 结尾回应开头提出的谜题，再自然引出下一章，不用机械的“更大阴谋即将开始”。

## 非虚构真实性守则

1. **事实**：同时代文献、档案、可复核实验或学术机构史料。
2. **历史解释**：现代科学史研究支持的归纳判断，需要标明属于解释。
3. **存在争议**：如氧气发现的优先权、梦中发现周期表等，明确标注争议。
4. **文学化组织**：允许倒叙、设问、跨时段对照、现代类比，但不能将其写成亲历实录。
5. 不伪造引语，不凭空描绘人物表情、对话、当天的天气或内心动机。
6. 原始史料在文末标注来源链接，关键数字与日期用脚注。版权不明确的历史图像只收集链接和权限说明。

## 每一章写作质量门槛

- 开头能立即明确一个历史异常，而非泛泛背景。
- 正文包含至少一次由证据支持的认识变化。
- 有至少两个具体实验／文献／可核实事件载体。
- 对竞争研究者贡献归属公平。
- 所有科学机制对普通读者可解释，且和当时知识区分。
- 结尾获得确定的知识收获，并接上下一章。
- 建议有5,000—9,000汉字的初稿；实际以叙事完整性为准。
- 完成后更新 `research/fact-check.md`，分“已核对”“待核实”，保持审校诚实。

## 本书前两章的结构样本

**序章（镓）**：1876年的密度异常 → 回溯1875年发现 → 1869/1871年空位与预测 → 1876年复测 → 科学预测的意义 → 1789年追溯。

**第一章（拉瓦锡）**：光／热为何在元素名单中、水为何不在 → 燃素说与金属增重 → 天平和氧气 → 操作性元素定义 → 33项结构及错误 → 命名法与多人协作 → 道尔顿问题。

## 推荐的独立审稿问题

- 读者是否能区分“有据事实”和“作者推断”？
- 是否把历史同行写成衬托主角的愚笨对手？
- 每一个数字和时间点能否追到一份具体资料？
- 是否出现为了强反转而使用的空洞断句？
- 即使删掉所有戏剧性形容词，本章是否仍有知识价值？
