# 第10章：一本写不下去的教科书

> 《空位——门捷列夫与元素周期表的发现》｜第三部：1869年，秩序诞生
>
> **稿件身份：完整候审正文 v1**，不代表正式\`draft/10.md\`通过写作闸门。承接[第9章](09.md)，下接[第11章](11.md)。[主张与来源](10.claims.json)及[史料审查范围](../research/ch09-12-source-audit.md)须随正文复审；现代演算与十九世纪原文严格区分。

## 一｜当你必须教会学生所有元素，麻烦才刚刚开始

假设你接过一份课程任务：向第一次系统学习化学的学生讲清楚当时已知的几十种元素。

你不能只把名字按字母排列。氯与碘虽然名字不相似，化学行为却有近亲关系；钠和钾都能形成具有相似组成规律的化合物，铜、锌却不能只因同样叫「金属」就被塞进它们中间。

你还不能把未来的原子序数写到黑板上。质子、电子排布都不属于1868年化学教师可以拿来推理的知识。

你只有化学反应、物质性质、相对原子量、化合价，以及一批尚在修正的测量数字。

**那么，一本化学教材应先讲谁、再讲谁？**

这不是普通的排版问题。若教材的顺序只是作者个人喜好，学生背完一章就得从头记下一章；若顺序反映物质性质之间的规律，读者才能从已知推向未知。

1868年前后，门捷列夫正在面对这样一项实际任务。他在圣彼得堡大学任教，并开始分册出版《化学原理》。这本书后来成了周期律历史中极重要的线索。[^1][^2]

但「一本写不下去的教科书」是本章用来提示知识困境的**叙事题目**，不是声称门捷列夫曾在日记里写下「我已经写不下去了」。

## 二｜为什么写书不是把研究成果搬进课堂？

回到1867年。门捷列夫出任大学化学教席，需要提供适于本国教学的系统课程。原有教材并不足以满足他的目标，编写一部俄语通用化学教材因此有直接的教学意义。[^3]

我们今天拿到一本标准教材，会以为学科的结构先天固定。

但在十九世纪六十年代，连某些关键术语都还在被争论：一种化学式到底表示分子组成，还是仅表示质量当量？一种物质的「原子量」如何由实验比值确定？相同化合价是否意味着相似化学性质？

第4章与第5章已经展示：阿伏伽德罗和坎尼扎罗的思想帮助化学家比较原子量，但实际研究界的记号统一需要时间。第6—8章又展示，即便原子量近于可比，尚古多、纽兰兹和迈耶仍会给出很不相同的元素排列。

所以教材作者不只是叙述一个已经封闭的体系。

他必须选择怎样让学生从**可实验证明的事实**走向**更一般的概念**，同时避免把尚未核实的假说写成自然法则。现代科学史研究也指出，《化学原理》的形成属于1868—1871年间教学、学术与俄国社会变化交织的过程。[^2][^4]

这些背景能解释问题的迫切，却不能直接证明某一天、某一段课堂讲授产生了周期表。

## 三｜第一批分册，暂时还可以顺着化学反应走

根据第一版出版研究，1868年5—6月左右，《化学原理》第一批印本已经出现，包含全书第一部分的前十一章。之后各部分直到1871年才陆续完成。[^2]

这比一句「他在1869年写出一本书」准确得多。

为什么分册出版重要？因为周期系统并不是作者在整部书写完之后才补上去的一张装饰图。它是在书稿继续生产、章节次序仍需安排时逐步出现的。

《化学原理》的早期内容可以从具体物质及其化合物讲起，例如水、氢、氧、氮、碳，继而讨论盐类、卤素及相关反应。今天看到的晚期英文译本仍保存这种由实验现象与物质体系进入理论问题的教科书路线。[^5]

注意，**晚期英译本的目录不是1868年首印各册的无差别照片**。不同版次、补充章节和译者整理都可能改变材料组织。我们可以用它理解作者长期重视的教学思路，却不能把某页后期注释直接当成1868年原稿。

这种写法一开始很有效。

讲水时，自然会碰到氢与氧；讲酸、盐与氧化物时，许多反应相互关联。学生可以沿着实验关系继续读下去。

但问题迟早会来：不相干的元素家族怎么办？

## 四｜同样是一价，为什么一个会和另一个大不相同？

先看两组元素。

氟、氯、溴、碘，今天归入卤素家族；锂、钠、钾，今天归入碱金属家族。在十九世纪，化学家已经能够利用相似反应与化合物组成关系辨认这类家族。

某些典型化合物的式子在现代记法下很相像，例如氯化钠 \(\mathrm{NaCl}\) 与氯化钾 \(\mathrm{KCl}\)，而氢与氯形成 \(\mathrm{HCl}\)。一价与组成比例给了我们可比的线索。

可是，「一价」本身并不足以解释全部化学行为。

氯与钠在形成氯化钠时扮演截然不同的角色。只要会写一对一的化合物，就把它们安排在同一族，会让学生在后续反应中不断遭遇反例。

为了更贴近当时的化学证据，可以同时看典型最高氧化物或氢化物、单质的反应性、与其他元素形成的盐类，以及相关原子量。

你就会发现，元素分类不能只沿着一条指示线前进。**原子量提供顺序，化学相似性提供家族，化合价与化合物比例则提供纠错标准**。

这些标准并非永远相安无事。

它们有时要求你给两个元素交换位置；有时需要承认某种测量值尚不够可靠。

## 五｜为什么不直接照着原子量从小到大念？

把元素依相对原子量排序似乎最公正。

在现代课堂里，我们可以将一串近似数写为：

| 元素 | 现代相对原子质量（约） |
|---|---:|
| Li | 6.94 |
| Be | 9.01 |
| B | 10.81 |
| C | 12.01 |
| N | 14.01 |
| O | 16.00 |
| F | 19.00 |
| Na | 22.99 |
| Mg | 24.31 |
| Al | 26.98 |
| Si | 28.09 |

这些**仅是帮助理解的现代近似数据**，不代表1869年每个元素都已被测到这些小数位，也不能把它们当作门捷列夫当日亲笔写下的完整表。历史数字可能不同，个别元素的性质和原子量也存在当时的争论。

从这串数据看，有一个惊人的现象：若暂时不考虑尚未认识的原子结构，从锂、铍、硼……到氟，某些特征沿排列方向渐变；越过氟，钠又在某些化学行为上与锂形成家族关系。

然而化学性质不是一条「原子量越大，性质越强」的单调曲线。

正是**重复**，而非单纯增大，让周期性成为可能。

但只用这十一个现代元素做例子还不够。要提出真正的规律，就得检查众多金属、非金属、化合价不同的元素以及异常值；不是靠一小段整齐的数字就宣布完成证明。

## 六｜钠和钾说得通，锌和铜往哪里放？

科学史学者埃里克·斯凯里分析门捷列夫1869年前后的笔记时，特别注意到一个教学次序难题：介绍卤素之后，怎样安排碱金属、碱土金属和介于其间的金属？现存笔记反映他曾比较不同原子量、当量与元素家族之间的关系。[^6]

这里出现了一张很有价值的纸：据相关史料研究，他曾在与一个地方奶酪合作组织有关的邀请文书背面做元素量值计算。研究者据此重建了他在化学家族之间选择连接路径的过程。[^6]

不要把这张纸幻想成「所有元素卡片第一次被洗开」的现场照片。

它更像一份尚未完成的数学草稿。存在一些计算，也存在需要历史解释的删改。它的价值不是为一个天才的瞬间提供布景，而是让后人看到：**研究者真的在处理具体的数与具体的排列选择**。

假如碱金属排列之后直接接上铜、银，某些化学相似性仍能讲得通；若安排碱土金属及其近亲，又能突出另一组性质联系。选择不同，后续其他元素的相对位置就会改变。

这不是玩文字游戏。

它说明周期律的发现不像从一堆杂物中挑出颜色相同的石头。每一项移动都要接受其他数据的追问。

## 七｜教材的真正矛盾：章节顺序需要一个原则

当你要写一门学科的全部内容时，局部的「相似」会与整体的「次序」相冲突。

三个卤素看起来很像，容易放在同一章节。

三个碱金属也很像。

可如果它们在原子量的整体排列中相隔很远，怎样才能同时保留这两种事实？如果把这些化学家族强行拆开，学生又如何看见相似性？

门捷列夫正在寻找的，最终不只是一份方便检索的名单，而是一种允许**两种约束同时存在**的表示方式：

- 沿某个方向保持原子量的大致顺序；
- 在另一个方向让性质相近的元素有机会对齐。

这两个条件听起来简单，一放进几乎全部已知元素就变得困难。

一些数据未必合适；一些元素没有完美邻居；一种氧化物式子可能暗示错置。后来更成熟的周期表允许修正原子量、保留空缺并依据性质判断位置。那些举措不应全被倒写到这本教材的最初一页。

在1868—1869之交，真正值得写的还是**原理形成中如何处理互相拉扯的证据**。

## 八｜一张“总表”有什么资格比一章章描述更重要？

尝试这样思考：如果每章介绍一种元素，课本就像一条长度不断增加的走廊，读者走到哪里才知道哪里有什么。

可若这些元素可以依据一组稳定规则排列，学生读到锂，就能预先理解钠、钾可能有哪些相似性质；读到氯，就会对溴、碘形成可检验的期待。

更重要的是，完整系统还可能向**尚未发现的元素**提出要求。

假设某个家族沿着原子量顺序应当继续，而对应的位置还没有被化学家确认，那么可选择的解释有好几种：规律本身错了，原子量错了，分类错了，或者——一种元素仍待发现。

一份分类表如果只把已有事实放得漂亮，并不太难被误用为记忆术。

一份敢于让未知位置留空、并由相邻元素推断未知性质的表，才更接近科学理论。

不过这一逻辑需要严格的时间线：**1869年首次提出系统时已有关于未知元素的一般性预见，1871年关于类铝、类硅等性质的系统数值预测才进一步成熟**。把成熟预言提前写入教材刚起笔时，会使发现过程显得过分神奇。[^7]

## 九｜1868—1871：一条连续的出版线，而不是一本书突然变身

依据日本科学史学者梶雅範（Masanori Kaji）及其他出版史研究，可把重要节点写得更具体。[^2][^8]

| 出版阶段 | 可定位的事件 |
|---|---|
| 1868年5—6月左右 | 《化学原理》第一部分的早期分册出现 |
| 1869年2月17日俄历／3月1日公历 | 第一份周期系统表注明日期 |
| 1869年3月6日俄历 | 门捷列夫的论文在俄罗斯化学学会会议上由门舒特金宣读 |
| 1869年春季 | 教科书后续分册继续出版 |
| 1870—1871年 | 全书剩余部分继续分批完成；周期系统论述也在修订 |

这里最重要的不是背每一个日期，而是不要说：「他先把书写完，然后偶然贴上一张周期表。」

事实恰好更有层次：**写书与建表在时间上彼此交叉**。

另外，旧俄历与格里高利历日期不能直接混算。1869年俄国使用的旧历与公历相差十二天，因此2月17日旧历对应3月1日公历。这里的「3月6日会议」沿用俄国事件报道口径；不同现代材料若只写“March 6”而未注明历法，正式审校须回原始会议记录核对。

## 十｜所谓“写不下去”，是科学问题不肯被略过

我们回到开头那位教科书作者。

眼前的难题并不是缺少可写的化学事实。相反，事实太多了，而且越积越多：新元素不断出现，原子量不断修正，化合物的式子不断标准化。

真正让人难以满意的是：如果没有更好的总原理，你就只能一页页告诉学生「它们相似」「它们不同」「这个例外请记住」。

那样的化学可以教学，却很难不断把未知转变成可推导的知识。

**所以，《化学原理》的写作压力不是某个天才被纸张逼到走投无路，而是一种更有生产力的压力：整门学科的丰富事实，正在要求一张能把不同章节连起来的地图。**

但我们还没有解释那张地图是如何画出的。

很多故事到这里会掏出一个纸牌盒，说门捷列夫开始像玩单人纸牌那样重新排列元素，随后在梦里见到了答案。

下一章，我们就要拆开这两层传说。

哪些纸张真的留存下来？哪些只是晚来的回忆？又有哪些分类步骤，即使没有卡片，也能由原始表格和化学逻辑重建？

**当你把传奇拿走，发现本身还剩下什么？**
