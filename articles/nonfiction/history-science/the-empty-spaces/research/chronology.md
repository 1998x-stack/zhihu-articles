# 关键事件时间线

| 时间 | 事件 | 核对备注 |
|---|---|---|
| 1774 | 普里斯特利等人关于氧气的实验与学术交流 | 氧气发现史需归属多位科学家 |
| 1787 | 道尔顿开始气象日记 | 后来坚持57年，留下大量观测记录 |
| 1787 | 多人合著《化学命名法》 | 居顿·德·莫尔沃、拉瓦锡、贝托莱、富尔克鲁瓦 |
| 1789 | 拉瓦锡《化学基本论》及33项简单物质表 | 含光、热素、三种假设酸根、五种土类 |
| 1793 | 道尔顿移居曼彻斯特并出版气象论文集 | 这一经历与气体研究相关 |
| 1794 | 拉瓦锡在法国大革命时期被处决 | 生活史与科学史需分开解释 |
| 1803-09-06 | 道尔顿笔记中的早期相对原子量表 | 是手稿日期，不等同1808年发表 |
| 1803（宣读）／1805（发表） | 道尔顿关于气体被液体吸收的论文 | 原子论起源不能简化为单一灵感 |
| 1807 | 汤姆森在《化学体系》中介绍道尔顿原子论 | 先于道尔顿1808年系统著作 |
| 1808 | 道尔顿《化学哲学新体系》第一部分出版 | 含原子符号、HO和简易组合规则 |
| 1808—1809 | 盖-吕萨克研究并发表气体化合体积关系 | 气体体积比较须同温同压；产物应指水蒸气 |
| 1811 | 阿伏伽德罗分子假说 | 对后来的原子／分子区别至关重要 |
| 1817 | 德贝莱纳比较钙、锶、钡相似性，成为三元素组先声 | 1829年本人论文回顾12年前的比较，1817年原文待核 |
| 1819 | 杜隆与珀蒂提出若干固体元素比热与原子量的经验近似关系 | 适用条件有限，不是普适严格定律 |
| 1823 | 德贝莱纳开展铂催化研究 | 也是其独立重要科学贡献 |
| 1826 | 巴拉尔发表溴的发现；勒维希较早有独立研究 | 区分研究与发表时间 |
| 1829 | 德贝莱纳发表《尝试按相似性分组基本物质》 | 15卷301—307页；三元素组不等于完整周期律 |
| 1855 | 洛朗《化学方法》英译本出版，奥德林比较并行的化学记号体系 | 水可写HO或H₂O：当量式与分子式不可混同 |
| 1858 | 坎尼扎罗《化学哲学课程提要》发表 | 利用气体分子假说改进相对原子量的推导 |
| 1859—1860 | 凯库勒、武尔茨与韦尔齐恩筹备化学家大会 | 邀请函指出科学讨论不具强制权 |
| 1860-09-03—09-05 | 卡尔斯鲁厄国际化学家大会 | 约140人参加，委员会提出有限记号建议 |
| 1860年9月会后 | 帕韦西帮助散发坎尼扎罗1858年《提要》 | 迈耶事后回忆其重要影响 |
| 1861 | 铷被发现 | 禁止把1889年含铷两行表当作1860年会场演示 |
| 1862-04-07 | 尚古多向法国科学院提交地螺旋分类 | *Comptes rendus* 54:757—761；未随正文刊完整图版 |
| 1862-04-14 | 圣克莱尔·德维尔回应尚古多 | 当年确有同行讨论，不可写成全体无人理会 |
| 1862-04-21、05-05 | 尚古多补充说明地螺旋 | 54卷840—843、967—971页 |
| 1862年秋 | 尚古多报告已石印元素分类图并送科学院 | 55卷600—601页，图版与论文应区分 |
| 1863 | 带有3幅彩色石印图的地螺旋印本出版 | 法国国家图书馆书目：21页+3图版 |
| 1863-02-07 | 纽兰兹在《化学新闻》讨论相似元素当量关系 | 尚未以1865年的“八音律”命名 |
| 1864 | 迈耶《化学的现代理论》发表，主表精选28种元素六家族 | 含硅—锡之间空位，其他辅助清单元素数另计 |
| 1864-07-30 | 纽兰兹讨论当量之差与简单数值关系 | *Chemical News* 10卷59—60页 |
| 1864-08-20 | 纽兰兹按相对重量依次为元素编号 | *Chemical News* 10卷94—95页；排序编号不是现代原子序数 |
| 1865-08-18 | 纽兰兹正式提出“八音律”，刊于《化学新闻》 | 12卷83页；七序号间隔，旧表有同位多元素 |
| 1866-03-01 | 纽兰兹在伦敦化学学会介绍八音律 | 格拉德斯通与George Carey Foster提出有记录的批评 |
| 1866-03-09 | 《化学新闻》刊载学会讨论记录 | 13卷113页，不能据此编造全场哄笑 |
| 1868（夏） | 迈耶拟成更全面的元素周期分类草稿 | 涉及过渡金属，52／53数目口径不同；1895才正式刊出 |
| 1869-02-17（俄国旧历）／1869-03-01（公历） | 门捷列夫早期元素周期系统 | 见 RSC 相关研究，视具体史料记述细化 |
| 1869年12月 | 迈耶准备其1870年元素原子量与原子体积论文 | 投稿日期依据史学来源，原刊编辑记录待核 |
| 1870 | 迈耶《元素性质作为其原子量函数》刊出 | *Liebigs Annalen*补编7卷354—364页，含原子体积周期曲线 |
| 1871 | 类铝、类硼、类硅的系统预测 | 不能提前归于1869年首稿 |
| 1875-08-27 | 据同期回顾，德布瓦博德兰观察到提示新元素的光谱线 | 待核对原报告日期 |
| 1875-09-20 | 法国科学院发表有关镓发现的报告 | 待核对原始会刊 |
| 1875-12 | 镓提纯／性质报道 | SRC-003 |
| **1876-05** | **初次镓密度约4.7的测量** | SRC-004与后续研究；绝不误写为1875年 |
| 1876（后期） | 镓密度重新测得约5.9 | 不同报道的精确数值需逐项核对 |
| 1879 | 钪被发现 | 需核对发现者／确证过程 |
| 1882 | 英国皇家学会向门捷列夫与洛塔尔·迈耶颁发戴维奖章 | 因元素原子量周期关系，非1860学会决定 |
| 1886 | 锗被发现 | 类硅预测得到重要确认 |
| 1887-11-08 | 皇家学会发信通知纽兰兹获戴维奖章 | 官方归档NLB/1/701，寄信人为Michael Foster |
| 1889 | 门捷列夫法拉第演讲回顾1860大会 | 列举原子量与当量对照，是事后例证 |
| 1893 | 迈耶生前曾获展示1868年保存的旧手稿 | 不是1895年才有任何人首次见到 |
| 1894—1898 | 稀有气体研究改变周期系统 | 注意氦的太阳光谱史早于此 |
| 1895 | 迈耶逝世；塞伯特整理刊出其1868周期分类手稿 | 公开刊出时间不能倒置为1868 |
| 1906 | 门捷列夫未获诺贝尔化学奖 | 需查诺奖档案 |
| 1907 | 门捷列夫逝世 | — |
| 1913 | 莫塞莱X射线谱研究 | 原子序数的物理意义进一步确立 |
| 1925 | 伦敦科学博物馆制作尚古多地螺旋模型 | 复原品，不是1862原实物 |
