## 序章的叙事切入口
一座城市有七座桥。人们想找到一条路线，让每座桥恰好被走过一次。看起来只要足够耐心，总能试遍所有走法。但问题真正的突破，来自一次出人意料的删减：道路有多长、桥怎样弯曲、河水向哪里流，都可以从问题里消失。留下来的只有四块陆地，以及它们之间的连接。
