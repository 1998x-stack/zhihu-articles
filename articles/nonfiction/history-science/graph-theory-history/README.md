# 连接的秩序：图论三百年
*The Order of Connections: Three Centuries of Graph Theory*

> 从七座桥，到无数个互相连接的节点：图论如何成为理解复杂世界的数学。

本系列为**历史与科学发现**类原创中文知识叙事，沿用本仓库的非虚构写作工作流。**当前序章00及第一部01—03章已有研究核证范围明确的初稿；04—37仍为占位卡。全书尚未进行独立连续性审核、结构审稿、精修或封版。**

全书采用“问题 → 旧方法失效 → 新的图论概念/定理 → 下一次矛盾”的知识叙事结构。计划七部36章，另有序章和尾声，约18万字。

## 序章的叙事切入口
一座城市有七座桥。人们想找到一条路线，让每座桥恰好被走过一次。看起来只要足够耐心，总能试遍所有走法。但问题真正的突破，来自一次出人意料的删减：道路有多长、桥怎样弯曲、河水向哪里流，都可以从问题里消失。留下来的只有四块陆地，以及它们之间的连接。
