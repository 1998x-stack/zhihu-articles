# 序章｜七座桥，为什么没有一条路能走通

假如有人告诉你：有一座城市，河上架着七座桥。无论从哪里出发，只要规定每座桥必须走一次、且只能走一次，你就不可能完成这趟散步。

你的第一反应是什么？

大概是想找一张地图。

看看河道怎样分叉，桥与桥之间隔着多远，哪里能掉头，哪条街能够绕过去。实在不行，再试几条路线。七座桥毕竟不多，总能把所有可能都走一遍。

可是，这道题最出人意料的地方就在这里。

**真正的答案，不需要一张精确的地图。**

桥是木头还是石头做的，不重要。桥长二十米还是两百米，不重要。街道如何弯曲，甚至河流究竟怎样蜿蜒，也不重要。

只要知道四块陆地分别连接着几座桥，就足以证明：没有人能够完成这场散步。

这不是因为路线太复杂，而是因为它在数学上根本不存在。

十八世纪，莱昂哈德·欧拉从这道看似无足轻重的城市谜题出发，找到了一种后来改变数学面貌的思考方式：**把世界的外形暂时拿开，只研究连接关系。**[GT00-01][GT00-03][GT00-08][GT00-13]

但在答案出现之前，先看一眼那个问题究竟是怎样提出的。

## 一｜地图越精确，答案反而越远

柯尼斯堡位于当时的普鲁士，是一座被普雷格尔河及其支流分隔的城市。河水绕过名为克奈普霍夫（Kneiphof）的岛屿，又与其他河间陆地及两岸相连。十八世纪的这片城区有七座桥，将四片陆地区域连接起来。[GT00-01]

我们不妨把它们记作 A、B、C、D。其中，A代表克奈普霍夫岛；其余字母代表另外三片陆地。这种用字母表示区域的方式，可以在欧拉那篇论文的英译节录中找到。[GT00-01][GT00-06]

问题很简单：

**能不能从任意一片陆地出发，连续走过七座桥，每座桥恰好经过一次？**

注意，这里有两个容易被改写掉的条件。

首先，一个人可以多次来到同一片陆地。不能重复的是**桥**，不是地面。你完全可以从A走到B，后来又从别的桥返回A。

其次，原问题**并不要求回到出发点**。起点和终点可以不同。即使允许这一点，七桥问题仍然无解。[GT00-02]

如果把这件事交给普通人的直觉，很自然会从“怎样走”开始。

先选一座桥，再选下一座。发现前面没有路了，就退回来，换一个方向。只要画出足够多的线路，似乎迟早能找到答案。

可是，画图并不等于证明。

假如你已经试了100条路线，100条都失败，只能说明你试过的这100条没有成功。

再试1000条，仍然不够。

除非你确信已经找遍了每一种可能，否则你无法从“我还没找到”推出“它一定不存在”。

这是七桥谜题的第一个真正困难：**证明一条路线存在很容易——走给别人看就行；证明它不存在，却不能只依靠不断失败的尝试。**

欧拉论文英译节录的第7节也提出了类似的工作方向：在费力安排各种字母顺序之前，应先找到判断这种安排是否可能的一般规则。[GT00-06][GT00-07]

问题的性质，已经悄悄改变。

我们不再是在找一条聪明的路。

我们是在问：**什么样的连接结构，才允许这样一条路存在？**

## 二｜他删掉了这座城市的大部分信息

为了理解这种转变，先做一件看起来很冒险的事。

把地图上的房屋删掉。街道删掉。河流的宽窄删掉。桥的长度和朝向也删掉。

只保留四个区域，以及七座桥分别连接哪两个区域。

在原论文相应的示意结构中，桥的连接关系可整理为：

| 两片陆地 | 相连的桥数 |
|---|---:|
| A—B | 2 |
| A—C | 2 |
| A—D | 1 |
| B—D | 1 |
| C—D | 1 |
| **合计** | **7** |

[GT00-01][GT00-06]

这张表已经不再像一座城市。它不告诉你码头在哪里，也无法帮助游客欣赏风景。

但它保留了完成题目所必需的全部信息。

因为只要允许人在同一片陆地内部自由走动，而跨越分隔区域的河流必须通过指定的桥，那么，走桥的次序就完全由这些连接关系决定。

今天，我们会把四片陆地画成四个**顶点**，把七座桥画成七条**边**。两片陆地之间可以有不止一座桥，因此这里更准确地说是一张允许平行边的图——多重图。[GT00-09][GT00-11]

但是，必须特别提醒：**这幅现代教科书式的“点与线”图，不是欧拉当时原样画出的数学对象。**

欧拉的论文使用示意地图、区域字母和表示行走顺序的字母串。后世熟悉的抽象图示，是对他思想的现代重述。若把今天标准化的圆点和线段直接画到1735年的欧拉手稿上，故事虽然直观，却会把数学史写错。[GT00-11]

欧拉真正迈出的关键一步，是发现一种路径可以不再被描述为“从某座街角向东走，然后向左转”。

它可以只是一串字母。

例如，假设一个人从A到B，再从B到D，最后从D到C。

我们可以写成：

**A → B → D → C**

这里有四个陆地字母，对应三次过桥。

这串字母几乎抹掉了整个现实城市，却精准保留了旅途经过哪些区域、发生了几次跨越。

而正是这种记法，将把一场复杂的寻找，压缩成一道令人无法回避的算术矛盾。[GT00-06]

## 三｜走七座桥，为什么一定要写八个字母？

接下来，是整篇故事里最值得慢慢理解的地方。

无论你怎样安排路线，只要恰好走过七座桥，就一定经历七次从一个区域到另一个区域的移动。

每次移动，都从一个区域出发，到另一个区域结束。

所以，如果把出发时所在的区域也写上，七次移动一定需要：

\[
7+1=8
\]

**八个陆地字母。**

这不是猜想。

假设你只过一座桥，路线记作AB，需要两个字母。

过两座桥，可能记作ABD，需要三个字母。

过三座桥，可能记作ABDC，需要四个字母。

以此类推，七次过桥，必定对应八个连续的区域位置。

注意，我们此时还没有要求路线真实存在，也没有选定从哪一座桥开始。

我们只是在说：**如果它存在，它的描述一定只有八个字母。**[GT00-07]

然后，欧拉去考察另一个数字。

不是桥的总数，而是**每一片陆地与多少座桥相接**。

A区域有五座桥接入。

B、C、D三个区域则分别有三座桥接入。

先看一个只有三座桥相接的区域。

如果你要把这三座桥全部走过，那么每次进入这里之后，通常还需要从另一座桥离开；进入与离开可以配成对。可三座桥是奇数，总有一座无法配对，只能留给旅途的开头或结尾。

因此，路线的字母序列中，这个区域至少要占据两个位置。

若有五座桥相接，道理相同：它至少需要占据三个位置。

这恰恰是欧拉在原论文第8—9节中采用的计数方向。[GT00-08]

现在，把四个区域的需求加起来。

| 区域 | 相接桥数 | 路线描述所需字母位置 |
|---|---:|---:|
| A | 5 | 3 |
| B | 3 | 2 |
| C | 3 | 2 |
| D | 3 | 2 |
| **总计** | **14次桥端连接** | **9个位置** |

[GT00-08]

问题出现了。

**走完七座桥，整条路线只有八个位置可写。**

**可是，四片陆地合在一起，至少需要九个位置。**

\[
3+2+2+2=9>8=7+1
\]

没有任何一种排列能让九个必要的位置，装进八个位置里。

因此，所要求的路线不可能存在。

它不取决于出发地点。

也不取决于你挑哪一座桥先走。

它更不取决于你愿意在城里绕多少圈。

你失败，不是因为尚未找到正确的顺序。

**是因为正确的顺序本身就不存在。**[GT00-08]

从一座城市，到四个字母，再到一个大于号，问题被缩小得几乎不可思议。

## 四｜用今天的语言，那九个字母究竟意味着什么

如果只记住“9大于8”，七桥问题还像一道精巧的智力题。

真正重要的是，我们能否从中抽出一条不依赖柯尼斯堡的规律。

现代图论为每个顶点引入一个基本量：**度数**。

你可以把它理解为：有多少条边与这个顶点相接。对这道没有自环的七桥多重图而言，就是有多少座桥连着该区域。

假设一个顶点的度数是4。

如果一次不重复边的行走经过它，而且它不是起点、也不是终点，那么我们每次走进来，都得沿另一条尚未走过的边离开。

进入一次，离开一次，正好消耗两条边。

进、出可以一对一配起来。

所以，普通的中途顶点，必须接着偶数条被这次行走使用的边。

那么奇数度数的顶点怎么办？

只可能有一种特殊解释：它是起点，或者终点。

因为起点可以少一次“进入”，终点可以少一次“离开”。这样的不配对机会，最多只有两个。

因此，若我们希望在一个连通的桥梁网络中恰好经过每条边一次：

**奇数度数的顶点只能有0个或2个。**

如果有2个，路线必须从其中一个出发，并在另一个结束。

如果一个都没有，则可以找到回到起点的闭合路线。

这是现代欧拉迹定理的表述；完整的充要条件还需要网络中所有有边的顶点彼此连通。此处说的是**后世标准化的数学定理**，不能将全部现代证明原封不动归于欧拉当年的论文。[GT00-09][GT00-12]

而柯尼斯堡呢？

四片陆地的度数分别是：

\[
5,\quad 3,\quad 3,\quad 3
\]

四个都是奇数。

一条路线最多能为两个奇度顶点提供“起点”和“终点”的特殊身份。

却没有四个。

这就是七桥问题无解的现代奇偶解释。

你会发现，它与原论文的九字母矛盾不是两套互不相关的魔法。

它们抓住的是同一个结构事实：

**进入一个地方和离开一个地方，必须服从成对的约束。**

欧拉的贡献，使这种非常普通的日常经验，变成了能够排除所有可能路线的数学理由。

## 五｜如果少一座桥，结局就可能完全不同

为了检验我们是不是真的理解了答案，可以做一个现代思想实验。

想象七座桥里，A与B之间的一座桥不再计入网络。

现在总共只剩六座桥。

四个区域的度数也会变成：

\[
4,\quad 2,\quad 3,\quad 3
\]

只有C、D两个区域仍然是奇度数。

按照刚才的规则，一条不重复桥的路线就有可能存在，从C出发，最后停在D，或者方向相反。

这一次，我们还能够具体给出一条路线：

**C → A → B → D → A → C → D**

它走过六座不同的桥：C—A的一座、A—B的一座、B—D、D—A、A—C的另一座，以及C—D。

每一座都恰好经过一次。[GT00-10]

请注意，这不是说十八世纪的柯尼斯堡曾经真的拆掉过某一座桥，也不是欧拉论文中的某次历史实验。

它只是我们今天使用原有连接结构做的一次数学检验。

但它揭示了一个很有意思的反转。

改变路线的聪明程度，没有用。

**改变一个连接关系，却可能直接改变整道题的答案。**

原来决定结果的，并不是一座桥看起来有多重要。

而是这座桥与哪些陆地相连，以及它怎样影响整个网络中的奇偶结构。

这也是图论思想令人着迷的原因之一：微小的局部连接改变，有时会决定一个全局任务究竟可不可能完成。

## 六｜“1736年，欧拉创立图论”——这句话少了一段历史

故事讲到这里，很容易出现一句顺畅的总结：

1736年，欧拉发表论文，图论从此诞生。

但真实的时间线，并没有这么简单。

欧拉研究七桥问题的成果可以追溯到1735年。根据数学史研究，他在1735年8月26日向圣彼得堡科学院报告了这一问题的解法。

1736年，关于问题与证明的通信仍在进行。现存历史研究讨论过丹齐希的卡尔·莱昂哈德·戈特利布·埃勒尔与海因里希·屈恩等人的联系，其中包括1736年3月9日一封涉及七桥问题的信。这至少提醒我们：数学发现未必是一个人孤零零坐在房间里突然获得启示，而可能牵涉提问者、通信和既有问题的传播。[GT00-04][GT00-05]

至于那篇后来著名的拉丁语论文，题为：

*Solutio problematis ad geometriam situs pertinentis*。

可以译为《与位置几何有关的一个问题的解答》。

它被收入圣彼得堡科学院期刊标为1736年的第八卷，但整卷实际在**1741年**才刊印出来。今天常说的“1736年七桥论文”，因此是沿用了成果和期刊卷次的传统年代说法，而不是严格意义上的实际出版年。[GT00-04]

更耐人寻味的是论文的题目。

欧拉并没有把它命名为《柯尼斯堡七座桥的散步技巧》。

他强调的是**位置几何**。

这一说法与莱布尼茨更早提出的几何思想有关：是否可能有一种几何，不再把长度、大小和角度放在中心，而是去理解位置与关系本身？

七桥问题似乎恰好给了这种思想一个具体的用武之地。[GT00-03]

这里也应该抵制另一种过于整齐的历史叙述。

我们今天把欧拉的工作视作图论的重要起点，并不意味着此前数学中完全不存在与连接、排列或关系有关的思考；也不意味着这篇论文已经拥有现代图论的一整套概念、定理与证明标准。

科学史不是一座楼房，某一天突然从地面长成完整的样子。

更多时候，它先出现一根关键的梁。

后人沿着它，才逐渐建起新的结构。[GT00-11][GT00-13]

## 七｜这不是关于散步的数学，而是关于“不可能”的数学

让我们回到开头的情景。

你站在柯尼斯堡，面前有七座桥。

如果不知道欧拉的思路，你会自然地去寻找一条路线。一旦失败，你可能怀疑自己选错了桥，或者还不够有耐心。

但欧拉给出的答案，根本不是一条更聪明的路线。

他给出了一种判断：

在开始寻找之前，先检查这个问题的结构是否允许答案存在。

这一步让数学从“尝试完成一项任务”，转向“研究完成这项任务所需要的条件”。

两者之间的距离，比它看上去大得多。

一条具体的路线，只能解决一张具体的地图。

而一个关于连接关系的定理，却可以被用于许多不同的桥梁、道路和网络，只要它们满足相同的数学条件。

由此延伸出去的问题将越来越多。

如果要让一张网络保持连通，最少需要哪些连接？

如果不能重复边，那么允许重复顶点会改变什么；反过来，如果要求每个顶点恰好访问一次，又会发生什么？

如果给边加上长度、费用或者容量，我们研究的就不再只是“能不能到达”，还会出现“怎样走最短”“怎样连接最省”“究竟能通过多少流量”。

后来的人们将发展树、回路、平面图、匹配、网络流、随机图和图算法。它们并不是从七桥结论中自动推出来的一条直线，但在一个更深的意义上，它们不断重复着同一类追问：

**一个复杂系统的整体行为，究竟被哪些连接规则所限制？**

所以，七桥问题最重要的答案，并不是“走不通”。

而是它让人看见：**有时候，找不到答案，不是因为我们缺少计算能力，而是因为我们尚未发现问题本身隐藏的结构。**

数学真正改变的，常常不是地图，而是我们观察地图的方法。

下一章，我们将回到欧拉的原始论证，从四块陆地、七座桥和看似朴素的进出配对开始，完整拆开这套逻辑：为什么有些网络能够一笔走完，而另一些无论如何都不行？

七座桥没有给行人留下一条完美路线，却给后来的数学留下了一条新的路。
