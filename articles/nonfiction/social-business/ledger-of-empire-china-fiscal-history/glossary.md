# 财政史术语口径与跨章一致性词典

| 术语 | 本系列工作定义 | 禁止的误用 |
|---|---|---|
| 财政 | 国家及其机构组织、取得、分配与使用资源的制度和活动 | 不限于现金，不等于现代政府预算 |
| 税人 | 刘守刚框架中以人口与力役为支点的汲取方式 | 不等于历代同一法定税目 |
| 税地 | 以田亩、土地收益及相应核定为征收支点的类型 | 不等同现代房地产税，不意味着没有人口要素 |
| 税商 | 作者框架中对工商业征税、官营或许可获取资源的集合 | 不等于仅征收“商税”，也不能类比所有现代税 |
| 税基与税柄 | 税基是课税依据或计量对象；税柄为作者便于解释的财政抓手 | 作者隐喻不可伪称古籍法定术语 |
| 正税与杂派 | 法定常规税课与各种附加、摊派、费用之区分 | 正税低不能代表社会总负担低 |
| 户籍与土地簿册 | 国家识别赋役承担者和土地关系的信息制度 | 文书设计不保证准确执行 |
| 均田 | 特定朝代土地分配/管理制度群 | 不自动等于全国土地平均私有 |
| 租庸调 | 唐前期租、庸、调相关赋役制度 | 不等于固定不变、全部地区无差别实行 |
| 两税法 | 唐中期按夏秋两期组织的税制改革 | 两税不是仅两种税目、不是现代单一财产税 |
| 盐利 | 国家盐业专营或相关制度获取的收益 | 不可一概写成净利润，须计成本 |
| 一条鞭法 | 明中后期多项赋役合并折银征收的改革实践 | 地区与年代存在差别，勿写全国一日完成 |
| 火耗归公 | 清雍正时对耗羡等行政经费的制度化处理 | 不等于地方陋规从此彻底消失 |
| 黄宗羲定律 | 后世对税费改革后负担反弹机制的概括 | 并非每次改革必然失败的严格自然定律 |
| 厘金 | 晚清军事财政背景下兴起的流通征费类型 | 不等于海关关税或现代增值税 |
| 度支部 | 晚清中央财政制度改造的重要机构 | 不等于完整现代预算体制已经建成 |
| 统收统支 / 财政包干 / 分税制 | 不同时期中国现代财政央地收入管理安排 | 区分法定收入划分、支出责任与转移支付 |
| 政府性基金与税收 | 现代财政收入不同预算口径 | 土地出让收入不得直接称作税收 |

**共同纪律**：不要跨朝代直接比较币值或税率。任何“财政收入占比”“军费比例”“人均税负”必须写出时间、币种、实物折算方法、地区、分母与史料性质。
