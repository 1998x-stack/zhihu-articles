# 信用、债务与权力：一部世界金融史

> **Credit, Debt and Power: A Global History of Finance**
> 从美索不达米亚的泥板到数字时代的资产负债表，金融史首先是人类如何发出承诺、让承诺流通、并在承诺无法兑现时重建规则的历史。

## 一、这本书究竟要回答什么

2008年9月15日，雷曼兄弟申请破产保护。它成为金融史上一个醒目的节点：对交易对手信用、资产估值和短期融资的怀疑迅速互相放大。为什么一家公司出现危机，会牵动跨越国家与行业的支付和融资网络？要回答这个问题，必须回到人类第一次系统记录债务的时代。

本书不是《历代金融大事记》，也不宣称金融发展遵循一条从原始到现代的必然阶梯。它追问：**债权何以可信？货币依靠什么被接受？国家为什么既能稳定金融又可能制造金融风险？金融创新如何扩大机会并重新分配风险？为什么危机会催生新的制度，而新制度又孕育新的漏洞？**

### 四条主要因果链

1. **债务—信用—中介—清算**：私人承诺如何变成可转让的票据、银行存款和证券？支付终局性、期限错配与挤兑从何而来？
2. **征税—战争—公债—货币权威**：财政需求如何改变铸币、国债、银行特许和央行制度？财政能力与国家信用如何互为条件？
3. **贸易—外汇—资本流动—国际秩序**：跨境结算、白银流动、黄金约束、美元体系及货币错配如何串联不同文明？
4. **创新—扩张—杠杆—危机—改革**：技术如何降低成本，激励如何推动风险积累，冲击如何通过资产负债表传播，规则如何调整？

### 贯穿全书的六组概念

| 重要区分 | 不能混为一谈 |
|---|---|
| 货币与信用 | 支付媒介、记账单位、债务承诺不是同一个概念 |
| 财富与流动性 | 资产有价值不代表任何时刻都能迅速变现 |
| 偿付能力与流动性 | 资产可能覆盖负债，却无法及时支付到期款项 |
| 金融创新与金融安全 | 转移风险不一定消灭风险，风险可能集中在新的节点 |
| 事件先后与可证因果 | 较早发生的事件未必是唯一甚至主要原因 |
| 地区经验与全球通则 | 中国、伊斯兰世界、印度洋、非洲、欧美各有制度路径 |

## 五、跨文明安排：不以欧美金融史替代世界金融史

- **中国**：秦汉财政、宋代交子、元明货币、清代票号钱庄、1935年法币改革、改革开放后金融制度和21世纪信用调整，作为连续叙事，而非个别趣闻。
- **伊斯兰世界与印度洋**：中世纪汇兑、合伙与信用共同体；与欧洲票据并列比较，不预设技术单向传播。
- **南亚与非洲**：南亚胡迪票据、印度洋与撒哈拉跨域贸易、非洲商路和殖民金融的不同形态；避免将非洲仅当作原料和劳动的背景。
- **欧洲与大西洋世界**：城邦财政、股份公司、国家银行、殖民扩张、工业证券与金本位；同时交代不平等和强迫劳动。
- **日本及东亚**：近代制度改革、日本泡沫、亚洲金融危机与中国现代化路径进行比较；不把各国当作单一亚洲样本。
- **美洲**：白银网络、美国中央银行、拉美债务周期、2008年危机，强调它们与全球系统的双向关系。

## 六、盐选式历史非虚构叙事：每章执行的统一公式

**真实场景／反常现象（Hook） → 旧制度为什么不够 → 参与者的利益与约束 → 关键行动或事件 → 核心机制的可理解拆解 → 至少一种竞争解释 → 直接后果及长期影响 → 下一章的新问题。**

每章初稿目标 4,500—6,500 汉字；重大制度转折可适当增加。前 150—250 字提出可核实的矛盾；概念解释采用「直觉例子→资产负债表/制度机制→适用边界」三层；不追求机械反转次数。每章至少回答“前一个制度为何不足、新制度解决何事、新制度又留下什么问题”。

**历史写作纪律**：不得编造真实人物对白、内心活动、报纸引语或并不存在的股价；对有争议的起源论、早期制度和危机归因，注明证据等级。叙事性重构只能帮助理解，必须和已核实的史实区分。参照仓库的 `chief-narrative-editor`、`genre-social-business`、`fact-research`、`story-architect`、`chapter-writer` 与 `developmental-editor` 技能流程。

### 建议采用的事件审计卡

| 字段 | 必填内容 |
|---|---|
| 事实与时间 | 精确到史料允许的时间尺度；确认日期、地区、制度名称 |
| 旧问题 | 既有支付、融资或监管安排遇到什么限制 |
| 参与者 | 立法者、商人、银行、家庭、债权人、债务人各自目标 |
| 机制 | 资金从谁的资产负债表流到谁、谁承担损失 |
| 触发条件 | 哪项政策、战争、价格、技术或信心变化触发转折 |
| 直接后果 | 可以从当时材料核验的变化 |
| 长期影响 | 对后来的制度变化作审慎归因，列明竞争解释 |
| 证据与反证 | 原始文件／学术文献／数据／争议或缺口 |
