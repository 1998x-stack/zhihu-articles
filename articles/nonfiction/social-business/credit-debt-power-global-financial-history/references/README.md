# 来源档案与可追溯证据

`source-ledger.csv` 为后续逐章核验使用的空白矩阵，**不代表已经完成文献阅读**。每一行至少记录：证据编号、对应章节、主张摘要、作者/机构、文献题名、年份、来源类型、URL/ISBN/馆藏号、具体页码或段落、访问时间、证据等级、分歧与备注。

引用规范：

1. 优先一手档案、官方统计与同行评议研究；媒体和通俗史仅作线索。
2. 网页引文写明作者、发布日期、URL与访问日期，历史文献写明具体版本、页码。
3. 对历史人物原话须核对原始出处；无来源的精彩对白不得写入正文。
4. 同一事件的机制结论尽量使用不同立场/方法的研究交叉比对。
5. 有争议的断言设为 `disputed` 或 `open`，不得伪装成 `verified`。
