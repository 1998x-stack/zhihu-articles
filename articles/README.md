# 作品归档说明

- `fiction/`：按现实逆袭、职场博弈、家庭伦理、悬疑推理、古风权谋、规则怪谈、AI科幻、青春成长归档。
- `nonfiction/`：按历史与科学发现、社会现实与商业调查归档。
- `_template/`：新建作品目录时复制这些文件。

每篇文章使用独立、小写 kebab-case slug，如 `articles/fiction/mystery-detective/missing-archive/`。不要把正式正文保存到 `.opencode/skills`。

状态建议：idea → outlined → drafting → reviewed → final。标注来源和原创性，不要把尚未核实的历史故事当作新闻事实。
